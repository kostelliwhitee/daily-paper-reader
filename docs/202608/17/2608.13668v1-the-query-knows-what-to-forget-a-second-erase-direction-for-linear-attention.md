## 摘要
线性注意力保持一个固定大小的状态。在长上下文中，许多存储项共享此状态，它们之间的干扰会降低检索性能。Gated DeltaNet-2（GDN-2）与此前的所有delta规则模型一样，其擦除向量源自当前令牌的键。然而，其读取中的干扰是通过查询来衡量的，而擦除步骤无法触及查询。我们引入了查询衍生的擦除方向（QED）。QED添加了一个源自查询且与键正交的第二擦除方向。在快速权重视角下，键定向的delta编辑无法改变读取中与键正交的部分。它利用可编辑部分来抵消沿查询测量的旧状态内容。它还在训练窗口之外的每个长度上改善了检索，并在S-NIAH-1上将可用上下文长度大约翻倍。

## Abstract
Linear attention keeps a state of fixed size. At long context, many stored items share this state, and interference between them degrades retrieval. Gated DeltaNet-2 (GDN-2), like every delta-rule model before it, derives its erase vector from the key of the current token. However, the interference in its reads is measured through the query, and the erase step cannot reach it. We introduce the Query-derived Erase Direction (QED). QED adds a second erase direction derived from the query and orthogonal to the key. In the fast-weight view, a key-directed delta edit cannot change the key-orthogonal part of a read. It uses the editable part to cancel old-state content measured along the query. It also improves retrieval at every length past the training window, and it about doubles the usable context length on S-NIAH-1.

## 一、核心问题与整体含义（研究动机与背景）

- 线性注意力（Linear Attention）用固定大小的循环状态替代 softmax 的序列长度缓存，使得推理时内存与每个 token 的序列混合计算量均为常数，但其代价是**所有历史关联都必须共享同一个有界状态**。
- 当上下文变长时，更多存储项被压缩进同一状态，相互干扰使检索质量显著退化。
- Delta 规则类模型（DeltaNet、Gated DeltaNet、KDA、GDN-2）的改进核心在于让状态更新更具选择性——通过“擦除”旧内容再写入新内容来修正错误关联。
- 但作者指出一个关键的结构性错配：**所有现有 delta 规则模型的擦除向量都源自当前 token 的键（key），而读取干扰是用查询（query）度量的**。键导向的 delta 编辑无法修改读取中与键正交的分量——即查询能“看见”的内容可能落在擦除无法触及的空间中。
- 本文提出的 QED（Query-derived Erase Direction，查询派生擦除方向）正是为解决这一错配：在键导向擦除之外，增加一个**源自查询、与键正交的第二擦除方向**，使模型能够擦除旧状态中沿查询方向残留的内容。

## 二、方法论：核心思想、关键技术细节与公式

### 2.1 核心思想

- 读取输出是状态沿查询方向的投影，干扰本质上也存在于查询方向；因此，擦除方向不应只由键决定，还应引入查询信息。
- QED 保持 GDN-2 的 rank-one 更新结构，只更换擦除向量：在原 `bt ⊙ kt` 基础上增加一个经门控、键正交化的查询项。

### 2.2 关键技术细节与公式

- **GDN-2 基础更新**：

  ```
  St = (I − kt at^T) Diag(exp gt) St−1 + kt (wt ⊙ vt)^T
  ```

  其中擦除向量 `at = bt ⊙ kt`。

- **QED 的擦除向量**：

  ```
  at = bt ⊙ kt + λh P⊥_kt(bt ⊙ qt)
  ```

  其中：

  ```
  P⊥_k(x) = x − k (k^T x)
  ```

  - `λh ≥ 0` 是每头学习的强度标量，由 `λh = λmax sigmoid(θh)` 约束，`λmax = 0.25`，`θh` 初始化为 `−2`（初始 λ ≈ 0.03）；
  - `bt` 是逐通道擦除门，对修正项也施加门控，避免每次读取都擦除内容；
  - 投影 `P⊥_kt` 保证新增方向与键正交，不改变 `I − kt at^T` 的非平凡特征值，维持稳定性条件。

- **在线学习（快权重）视角**：

  - 对任意探针 `x ⊥ kt`，键导向 delta 更新无法改变其读出响应（公式 9）；
  - 将查询分解为 `qt = ρt kt + q⊥_t`，其中 `ρt = qt^T kt`，`q⊥_t` 是查询中与键正交的部分；
  - GDN-2 的输出中，`S̄_t^T q⊥_t` 这一项是旧状态中被查询读出、但键导向擦除不可达的内容；
  - QED 沿 `dt = P⊥_kt(bt ⊙ qt)` 采样旧状态并将其负值沿键写入，从而精确抵消这一残留：
    ```
    o_QED_t = o_GDN2_t − λh ρt S̄_t^T dt
    ```

- **实现开销**：每个 token 每头仅增加一次点积和一次减法，计算代价可忽略。

## 六、主要结论与发现

1. **长上下文检索显著提升**：QED 在 S-NIAH-1 上于训练窗口（2048 tokens）外的所有评估长度均优于 GDN-2，最高提升达 39 个百分点；在相同精度水平下，可用上下文从约 8K 扩展到约 16K。
2. **FDA 召回提升**：两个种子上分别提升 3.4 和 3.7 个百分点；SWDE 结果不稳定（seed 0 小幅提升、seed 1 无效）；SQuAD-completion 基本无变化。
3. **语言建模质量不受影响**：验证损失在全部 10 次运行中差异极小（同一 seed 内 ≤0.0013 nats），说明 QED 针对检索而非语言建模。
4. **查询方向是关键**：QED 在几乎所有外推长度上显著优于随机方向对照（QED-rand），支持“查询含干扰信息”的核心论点。
5. **门控与投影的单独贡献不确定**：两维度各自的效果在 seed 间不一致；投影的稳定性约束在实测中未激活（1.18M 样本上未投影模型的非平凡特征值始终落在 [−0.011, 0.985]，投影前后变化 <10⁻³）。
6. **推理时强度测试**：一个 checkpoint 随强度增大精度单调提升（16K 处 44.8%→73.0%），另一个基本不敏感；说明训练好的模型可能但并非必然依赖该修正。

## 七、优点

- **问题诊断精准**：借助快权重/在线学习视角，公式（9）—（12）严谨地指出了键导向 delta 编辑无法触及查询正交分量的结构性缺陷，动机清晰、理论支撑扎实。
- **方案极简且低开销**：只修改擦除向量，保持 rank-one 更新与稳定性条件，额外计算仅为一个点积和一次减法。
- **消融设计严谨**：方向、门控、投影三个维度分别设对照，还引入随机方向控制组；双种子设计增强了可比性。
- **投影效果分析深入**：通过实测特征值分布说明投影在当前规模下是“未激活的安全带”，这种诚实且精细的机制归因值得借鉴。
- **推理时强度测试有启发性**：在不重训练的情况下探索模型对修正强度的依赖，为后续 λ_max 训练时扫描提供了依据。

- **理论分析基于理想化假设**：快权重视角下的推导假设了单步更新的线性结构与正交分解；但在多层、多头、非线性门控的网络中，“读出的干扰仅存在于查询方向”这一结论可能被弱化，理论到实际之间仍有跳跃。

## 九、总结

QED 以极低的计算开销（每 token 每头仅增加一个点积和一次减法）修正了 delta 规则类模型在“查询方向擦除”上的结构性盲区，在长上下文精确检索（S-NIAH-1）上带来了显著且跨种子稳定的提升，同时不损害语言建模损失；其问题诊断、公式推导、消融设计和推理时强度分析都体现了较高的研究水准。然而，受限于单一模型规模、单一训练数据、有限的最长上下文以及部分组件级结论在 seed 间的不一致，QED 目前更适合被视为一个“机制清晰、初步验证有效”的改进方向，而非已被充分证明的通用解法。未来若能在更大规模模型、更多训练数据、更长序列上开展系统验证，并公开更完整的算力与复现细节，其结论将更具说服力。
