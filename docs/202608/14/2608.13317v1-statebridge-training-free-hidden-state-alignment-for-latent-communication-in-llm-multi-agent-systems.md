## 摘要
基于大型语言模型的多智能体系统通常以文本（即离散标记）进行通信。然而，文本引入了离散瓶颈。将发送方的连续隐状态转换为离散标记会丢弃仅靠标记身份无法捕获的信息。近期工作提出潜在通信作为替代方案，即智能体直接传输隐表示而不将其转换为文本。然而，现有潜在方法要么在Transformer各层逐层注入工作记忆，要么需要训练投影器从而限制可移植性。我们提出StateBridge，一种无训练的潜在通信方法，通过闭式正交变换将发送方的最终层隐状态对齐到接收方的输入空间。轻量级范数校准和词汇表锚定确保与预训练输入分布兼容。对齐后的状态作为连续前缀添加到接收方智能体的输入之前。我们在数学推理、代码生成和问答任务上，使用来自两个家族的四个模型评估了StateBridge。StateBridge在26个模型-任务对中的22个上取得最佳或并列最佳分数，持续优于最强基线。

## Abstract
Large language model based multi-agent systems usually communicate in text, i.e., using discrete tokens. However, text introduces a discrete bottleneck. Converting the sender's continuous hidden states into discrete tokens discards information that token identities alone cannot capture. Recent work proposes latent communication as an alternative, where agents transmit hidden representations directly without converting them to text. However, existing latent methods either inject working memory layer by layer across the transformers, or require trained projectors that limit portability. We propose StateBridge, a training-free latent communication approach that aligns the sender's final-layer hidden states to the receiver's input space via a closed-form orthogonal transformation. Lightweight norm calibration and vocabulary anchoring ensure compatibility with the pretrained input distribution. The aligned states are prepended to the input of the receiver agent as a continuous prefix. We evaluate StateBridge on math reasoning, code generation, and question answering with four models from two families. StateBridge achieves the best or tied-best score on 22 out of 26 model-task pairs, consistently outperforming the strongest baseline.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：现代多智能体（Multi-Agent, MA）系统由多个 LLM 智能体协作完成复杂任务，而智能体之间的通信质量直接影响系统性能。主流通信方式为自然语言文本，即通过离散 token 传递信息。
- **核心痛点**：文本通信存在“离散瓶颈”（discrete bottleneck）。发送方必须将连续的内部隐状态压缩为离散 token，这一过程会丢弃 token 身份无法捕获的连续信息，造成信息损失；接收方仅能通过嵌入层恢复 token 身份，无法还原发送方的原始隐状态。
- **现有潜在通信方法的不足**：
  - **KV-cache 传输方法**（如 Cache-to-Cache、LatentMAS）：虽然避免了输入层错配，但需要跨所有 Transformer 层注入工作记忆，传递的是内部处理状态而非完整消息的紧凑表示，且对层结构敏感，跨模型家族可移植性差。
  - **学习式潜在通信方法**（如 Interlat、ThoughtComm）：通过训练投影器桥接隐状态与输入空间，但投影器与特定模型和任务绑定，更换模型需重新训练。
- **研究核心问题**：能否**仅通过对齐（alignment）**，无需训练或架构修改，就让现成的 LLM 智能体通过连续表示（隐状态）进行有效通信？

## 2. 方法论：StateBridge

### 2.1 总体思想
- 核心观点：潜在通信只有同时满足两个条件才能生效——**(1) 传输的状态富含信息**（保留发送方隐状态的连续信息），**(2) 传输的状态与接收方输入空间兼容**（可被接收方直接处理）。
- 方法定位：在输入嵌入层操作，通过**闭式变换**将发送方最终层隐状态对齐到接收方输入嵌入空间，生成连续前缀注入接收方输入，全程无训练、无架构修改。

### 2.2 关键技术步骤

**（1）消息提取（Message Extraction）**
- 保留发送方生成消息最后 K 个 token 的最终层隐状态：`S = (s1, ..., sK)ᵀ ∈ Rᴷˣᵈ`
- 对含思维链（如 Qwen3 的 `<think>`）的模型，丢弃中间推理段落，仅保留面向接收方的消息段。
- 在共享词嵌入矩阵中查找对应 token 的嵌入作为参考：`R = W_emb[y] ∈ Rᴷˣᵈ`。离散 token 本身不传输。

**（2）对齐接口（Alignment Interface）**——三步闭式流程：

- **Procrustes 对齐（正交 Procrustes）**：
  - 将 S 和 R 视为两个点云，先分别中心化，再白化（whitening），使主方向尺度均衡。
  - 求解正交 Procrustes 问题：`min_Q ||SwQ - Rw||²_F  s.t. QᵀQ=I`，闭式解为 `Q* = UVᵀ`（SVD）。
  - 正交变换保留点云内部成对距离和角度（几何结构），避免任意剪切。
  - 最后恢复参考空间的尺度和位置：`S~ = SwQ*Σ_R^{1/2} + 1_K μ_Rᵀ`。

- **范数校准（Norm Calibration）**：
  - 问题：最终层隐状态范数远大于 token 嵌入（Qwen3-4B 上约大 140 倍），会主导注意力分数。
  - 操作：将每个对齐向量缩放至词汇嵌入的平均 ℓ2 范数 `n̄`：`ŝᵢ = s̃ᵢ · n̄ / ||s̃ᵢ||₂`。

- **词汇锚定（Vocabulary Anchoring）**：
  - 操作：将每个缩放后的向量向余弦相似度最近的词汇嵌入微移：`s̄ᵢ = (1 - α)ŝᵢ + α·W_emb[v*]`，其中 α∈[0,1]，默认 0.3。
  - 目的：不是将状态离散化为 token，而是保持连续性的同时，使其靠近预训练时熟悉的输入嵌入区域，增强可读性。

**（3）前缀注入（Prefix Injection）**
- 将最终对齐前缀 `S̄` 与接收方 prompt 嵌入拼接：`X = [S̄; P] ∈ R^(K+N)×d`。
- 直接以 `inputs_embeds` 方式注入，绕过 tokenization，位置编码按顺序分配，接收方无需任何架构调整。

### 2.3 计算成本
- **时间**：对齐复杂度由白化特征分解 O(d³) 和词汇锚定搜索 O(KVd) 主导，均低于单次自回归生成 O(TLd²) 的成本。
- **空间**：通过 forward hook 仅记录最终层输出，提取成本 O(Td)，保留最后 K 个状态为 O(Kd)；对比 KV-cache 方法需 O(TLd) 存储，显著更省。

## 6. 主要结论与发现

- **StateBridge 在 26 个模型-任务对中的 22 个上取得最佳或并列最佳分数**，在四个模型设置中的平均分均超越最强基线，提升幅度为 2.4~2.9 个百分点。
- **跨模型家族稳健性突出**：在 OLMo3-7B-Think 上，LatentMAS 平均只有 55.1%，远低于 TextMAS 的 73.9%，而 StateBridge 达到 76.7%，说明 KV 注入方法对层结构敏感，而输入层对齐方法通用性更强。
- **挑战性任务增益更大**：StateBridge 在 MedQA、GPQA、AIME24/25 和代码生成任务上提升最为显著，而在 GSM8K 等较简单任务上有时略逊于基线（可能由于连续前缀影响精确匹配下的输出格式）。
- **消融验证**：
  - 用岭回归替换正交 Procrustes 导致平均分从 82.4% 降至 74.9%，代码任务下降尤其严重（如 HumanEval+ 从 82.3% 降至 63.6%），证明几何结构保留是关键。
  - 去掉范数校准和词汇锚定分别下降 2.9 和 2.2 个百分点，说明兼容性步骤不可缺失。
  - 随机噪声前缀几乎摧毁性能（平均 48.8%），排除了“额外向量本身有效”的混淆解释。
- **案例研究支持**：critic 仅从对齐前缀中能恢复比可见后缀 token 更丰富的信息（如更精确的医学名词“koilonychia”），证明前缀携带了超出离散文本的连续语义。

## 7. 方法/实验亮点

- **真正免训练**：无需任何可学习参数，采用闭式正交变换、范数校准和词汇锚定，即插即用，可迁移到任意同构 LLM。
- **架构无关**：仅在输入嵌入层注入，适用于不同层结构的模型家族，对比 KV 注入方法具有明显工程优势。
- **理论支撑严密**：通过互信息界说明文本通信的信息瓶颈；通过命题证明岭回归将前缀限制在 token 嵌入张成空间内，而正交 Procrustes 保留等距性；为几何对齐优于点态拟合提供了严格依据。
- **成本可控**：对齐复杂度 O(d³)+O(KVd)，空间 O(Kd)，显著低于 KV-cache 的 O(TLd)，适合实际部署。
- **设计细致**：Norm 校准解决注意力主导问题，词汇锚定兼顾连续性与输入分布兼容性，超参数选择在验证集上确定后固定用于所有评测，避免过拟合。

## 8. 不足与局限

- **同构假设**：方法要求所有智能体共享同一模型和词表。论文明确将“异构模型”列为未来工作，这限制了其在更一般多智能体系统中的适用性。
- **固定前缀长度**：K=64 对所有任务固定，K 过大会降低对齐质量（全局单一旋转难以适配异质状态），过小则信息不足；缺少自适应长度机制。
- **与学习式方法对比缺失**：没有与需要训练的潜在通信方法（如 Interlat、ThoughtComm）进行实验对比，虽有理论上的可移植性优势，但实际性能差距未量化。
- **统计显著性未报告**：未提供多次运行的方差，无法判断某些小幅下降（如 GSM8K 上 -2.6）是否噪声所致。
- **任务覆盖偏向**：数学、QA、代码三类任务虽广，但未涉及工具调用、长期规划、对话交互等更复杂的多智能体应用场景；文本问题中的具体效果（如输出格式干扰）未深入分析。
