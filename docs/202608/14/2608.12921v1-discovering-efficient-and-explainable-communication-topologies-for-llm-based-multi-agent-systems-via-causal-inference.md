## 摘要
基于大语言模型（LLM）的多智能体系统（MAS）的性能在很大程度上取决于有效的通信拓扑。然而，现有的拓扑生成方法通常仅通过任务级奖励驱动的黑盒优化来学习通信拓扑。虽然有效，但这种优化几乎无法解释为何选择特定的通信边，使得难以识别对成功协作起关键作用的通信子图。为解决这一局限，我们提出E2-Explainer，一个模型无关的框架，用于为任意拓扑生成器产生的通信拓扑提供可解释的解释。具体而言，我们将拓扑解释表述为一个因果归因问题，该问题识别由任务保留的边级证据支持的紧凑通信子图。我们通过一种Granger风格的目标函数获得该证据，该目标函数衡量掩蔽每个通信通道如何改变任务结果和最终响应的稳定性。然后将所得的有预算子图蒸馏到一个摊销解释器中，从而在部署时无需重复进行边级评估即可实现高效的事后解释。在多个推理和编码基准上的广泛实验表明，E2-Explainer能够识别保留成功协作的关键通信子图。这些子图还可以直接执行以修剪冗余通信边，在保持竞争性任务性能的同时大幅降低通信成本。

## Abstract
The performance of large language model (LLM)-based multi-agent systems (MAS) largely depends on effective communication topologies. Existing topology generation methods, however, typically learn communication topologies through black-box optimization driven solely by task-level rewards. While effective, such optimization provides little insight into why particular communication edges are selected, making it difficult to identify the critical communication subgraphs responsible for successful collaboration. To address this limitation, we propose E2-Explainer, a model-agnostic framework for providing interpretable explanations of communication topologies produced by arbitrary topology generators. Specifically, we formulate topology explanation as a causal attribution problem that identifies compact communication subgraphs supported by edge-level evidence of task preservation. We obtain this evidence with a Granger-style objective that measures how masking each communication channel changes the task outcome and the stability of the final response. The resulting budgeted subgraphs are then distilled into an amortized explainer, enabling efficient post-hoc explanation without repeated edge-level evaluations at deployment. Extensive experiments on multiple reasoning and coding benchmarks demonstrate that E2-Explainer identifies critical communication subgraphs that preserve successful collaboration. These subgraphs can also be executed directly to prune redundant communication edges, substantially reducing communication costs while maintaining competitive task performance.

## 1. 核心问题与整体含义（研究动机和背景）

- 在基于大语言模型（LLM）的多智能体系统（MAS）中，通信拓扑直接决定信息流、协作效率与任务表现。已有拓扑生成方法（如 G-Designer、ARG-Designer、OFA-MAS、AgentPrune）通常通过黑盒优化，仅以任务级奖励为信号学习通信图。
- 这种优化范式存在两个缺陷：  
  - **冗余性强**：随机掩蔽实验表明，删除部分边对最终任务影响很小，甚至有时因移除干扰信息而提升性能，说明生成拓扑中存在大量与成功协作仅“相关”而非“因果”的边。  
  - **缺乏可解释性**：黑盒优化无法揭示“为什么选择这条边”或“哪些通信子结构真正决定协作成败”。
- 因此，作者提出需要一种**事后解释框架**，从已生成拓扑中识别“因果关键”的紧凑通信子图，既能解释协作成功的机制，又能通过修剪冗余边降低通信成本。

## 2. 方法论（E2-Explainer）

- **核心思想**：将拓扑解释建模为**因果归因问题**，借鉴 Granger 因果思想——若某条边携带的信息能提升 MAS 协作性能，则该边具有因果重要性。通过掩蔽边并观测任务结果变化来评估边长级贡献。
- **关键技术流程（三步）**：
  1. **边级 Granger 风格因果归因**  
     - 对每条活跃边 \(e =(u,v)\)，构造干预图 \(G_{-e}=G\setminus\{e\}\)，重新执行 LLM-MAS，计算任务级贡献：  
       \[
       \Delta^{\text{task}}_e = Q(x,G) - Q(x,G_{-e}),\quad u^{\text{task}}_e = \max(0,\Delta^{\text{task}}_e)
       \]
     - 引入辅助信号——**结果级语义熵**（semantic entropy）衡量最终响应的稳定性：对多次随机执行的结果进行语义聚类，计算熵 \(\bar{H}(Y)\)，定义  
       \[
       u^{\text{sem}}_e = \max(0,\bar{H}(Y_{G_{-e}})-\bar{H}(Y_G))
       \]
     - 合并为统一边效用，经归一化与裁剪得到边保留排序 \(\pi_G\)。
  2. **预算化因果子图提取**  
     - 给定预算 \(b=(\rho_E,\rho_V)\)，转换为保留边/节点数，按效用排序取 TopK 边，再经**可执行性约束投影** \(R_{\text{valid}}\) 生成紧凑子图 \(H^*_b\)（保留必要输入/聚合节点，移除不参与有效路径的可选节点与边，不新增链接）。  
     - 对多个预算得到解释族 \(F^*(x,G)=\{H^*_b\}\)，刻画效率-性能权衡。
  3. **摊销解释器（Amortized Explainer）**  
     - 离线提取的“图-子图”对作为监督，训练参数化解释器 \(F_\theta(x,G,b)\)，预测边/节点的保留概率。  
     - 测试时只需一次前向传播，经由 TopK 和无效投影输出子图，**无需任务标签、无需重复掩蔽评估**。  
     - 训练损失为边级和节点级二元交叉熵之和，加权重衰减。

## 6. 主要结论与发现

- **E2-Explainer 能同时提升性能与效率**：作为后处理模块，将 4 个优化器的 token 消耗降低 20.1%–25.6%，同时将平均准确率提升 0.44–1.09 个百分点。其中 G-Designer+E2-Explainer 平均准确率最高（90.71），token 减少 25.1%。
- **跨生成器和跨规模泛化有效**：只基于 G-Designer 训练的冻结解释器，可直接应用于未见过的 ARG-Designer、OFA-MAS、AgentPrune，也适用于 5→6 个智能体的规模迁移（MMLU 提升 2.27 点、HumanEval 提升 0.82 点，同时显著减 token）。
- **任务级因果信号是主导，语义熵辅助信号补充**：消融实验显示，去掉因果信号后准确率大幅下降（MMLU 从 79.74 降至 75.82），去掉语义熵也会下降（降至 77.78），两者结合最佳。
- **手动拓扑泛化证明解释器学到的是通用通信模式**：对 complete、random、layered、chain、star 等固定拓扑，E2-Explainer 在 30 个数据集-拓扑组合中改善了 26 个，且所有组合均缩减 token；链式拓扑因本身稀疏提升有限。
- **冗余≠可任意剪枝**：随机掩蔽多数会损害性能，只有少数随机掩蔽能保持或改善结果，说明需要因果引导而非随机删边。

## 7. 优点

- **模型无关性**：不访问拓扑生成器内部参数，仅依赖“图 + 查询 + 角色信息”，适用于任意生成器甚至手工拓扑。
- **可解释性**：明确给出每条边/每个子图的因果贡献，回答“为什么保留这些通信”的问题。
- **部署高效**：离线进行因果评估，部署时经摊销解释器一次前向即可输出子图，无需 LLM 反复执行。
- **实际代价度量**：直接报告在线 token 使用，而非仅用边数/密度作为代理指标，揭示“结构稀疏不等于 token 节约”这一重要现象。
- **实验设计严密**：多个泛化场景、预算扫描、消融、案例研究，且刻意固定预算以避免各方法单独调优的不公平比较。

## 8. 不足与局限

- **骨干模型单一**：全部实验基于 Qwen3-8B，未验证在其他规模和厂商的 LLM 上的普适性。
- **因果归因是一阶近似**：仅评估“所有其他边保持不变时移除一条边”的条件贡献，未考虑多边联合掩蔽或协同效应，可能遗漏冗余但是互补的边组合；附录也承认此点。
- **校准开销大**：离线构建监督需要逐边反复执行 LLM（每边 5 次），当边数或智能体规模较大时成本可能很高，摊销只能降低测试阶段成本。
- **预算选择依赖经验**：默认 E25+N20 是在 G-Designer 图上扫描得到的“全局”折中点，并非对所有生成器最优。更激进的节点剪枝（如 N40）会导致明显性能损失（HumanEval 下降 6.52 点），说明剪枝有风险。
- **随机性导致的结果波动**：案例研究表明，正确/错误转换可能受到解码采样随机性影响，作者虽然用独立执行说明，但无法严格证明“剪除某边导致错误”这一因果断言。
- **规模覆盖有限**：跨规模实验仅测试 5→6 个智能体，未验证更大规模（如 10+）下的泛化能力。
