## 摘要
基于LLM的多智能体系统（MAS）通过协调多个智能体在复杂推理任务上取得了强大性能，但代价是大量的token消耗。最近关于自动拓扑设计的工作ARG-Designer将这个问题重新表述为自回归图生成。然而，其训练目标并未明确激励模型生成稀疏且高效的拓扑。我们通过引入一种受人类反馈强化学习（RLHF）启发的奖励引导自回归图生成（RGA-Designer）来解决这一局限性。我们训练了一个奖励模型，该模型同时捕获任务正确性和结构紧凑性，然后使用奖励模型作为反馈对预训练的图生成器进行微调。我们的方法在保持与ARG-Designer相当的任务准确率的同时，平均减少了20.5%的token消耗。

## Abstract
LLM-based Multi-Agent Systems (MAS) achieve strong performance on complex reasoning tasks by coordinating multiple agents, but at the cost of substantial token consumption. Recent work on automatic topology design, ARG-Designer, has reframed this problem as autoregressive graph generation. However, its training objective provides no explicit incentive for the model to generate sparse and efficient topologies. We address this limitation by introducing a Reward-Guided Autoregressive Graph Generation (RGA-Designer) inspired by Reinforcement Learning from Human Feedback (RLHF). We train a reward model that jointly captures task correctness and structural compactness, and then fine-tune the pretrained graph generator using the reward model as feedback. Our method preserves task accuracy at the level of ARG-Designer while reducing token consumption by an average of 20.5%.

- **研究意义**：本文尝试在保持任务准确率的前提下，显著降低多智能体推理时的 token 开销，使 MAS 在实际应用中更加经济高效。

## 2. 方法论：核心思想、关键技术细节

- **总体思路**：借鉴 RLHF（基于人类反馈的强化学习）范式，将“人类反馈”替换为**可编程验证的规则奖励**，属于“带可验证奖励的强化学习”（RLVR）范畴。通过训练一个图级奖励模型，引导自回归图生成器产出“正确且紧凑”的拓扑结构。
- **整体流程（三阶段 + 预训练前置）**：
  1. **预训练生成器（阶段 0）**：沿用 ARG-Designer 训练好的自回归图生成器作为初始策略。
  2. **数据集收集（阶段 1）**：对每个任务查询采样多个候选图，在底层 LLM 上执行，根据是否成功完成任务标注为成功/失败，并额外纳入 ARG-Designer 训练阶段的样本以降低成本。构建偏好对（成功样本 vs 较不优样本）。
  3. **奖励模型训练（阶段 2）**：设计一个图级奖励模型（基于 GraphSAGE + MLP），综合任务正确性、智能体数量和边数量给出奖励分数，使用 Bradley-Terry 排序目标训练。
  4. **策略优化（阶段 3）**：采用 Group Relative Policy Optimization（GRPO）在线策略优化，以奖励模型输出作为优势信号，并用 KL 散度约束使生成器不过度偏离参考模型。
- **关键公式与设计**：
  - **奖励公式**：  
    \( r = \lambda_c c + \lambda_V \max(0, (V_{max}-|V|)/(V_{max}-1)) + \lambda_E \text{clip}(0,1, (E_{max}-|E|)/(E_{max}-E_{min})) \)，权重 \(\lambda_c=0.6, \lambda_V=0.3, \lambda_E=0.1\)，确保“正确性”权重最高。
  - **偏好对构建**：要求至少一个样本成功，且奖励差 > 阈值 δ（0.05），避免无效比较。
  - **奖励模型输入**：节点特征 = 角色嵌入 ∥ 查询嵌入 ∥ 结构特征（图大小、边数、生成顺序位置、入度、出度），通过两层 GraphSAGE 编码，全局池化后经 MLP 输出标量。
  - **策略优化目标**：  
    \( \mathcal{L}_\pi = -\hat{A}_i \log \pi_\theta(G_i|q) + \beta \log[\pi_\theta(G_i|q)/\pi_{ref}(G_i|q)] \)，其中优势通过组内归一化的奖励得到（GRPO 方式）。
- **额外优点**：奖励模型在嵌入空间打分，可泛化到未见过的角色，因此训练数据可以跨数据集共享，无需为每个数据集重新训练结构分类头。

## 6. 主要结论与发现

- **准确率**：RGA-Designer 在 6 个基准上与 ARG-Designer 准确率基本持平（多数差异在统计上不显著，且所有准确率下降均不显著），甚至在人道评估上略有提升（如 HumanEval 83.22% vs 82.56%）。
- **token 消耗**：相比 ARG-Designer，平均降低 **20.5%** 的 token 使用量；在 6 个基准中，5 个达到统计显著（MultiArith 除外）。
- **原因分析**：MultiArith 问题来自模板化生成、语言变化少、冗余结构少，因此可压缩空间有限。
- **额外益处**：奖励模型在嵌入空间工作，可跨数据集复用，避免因新增角色而需要重训生成器结构分类头。

## 7. 方法亮点

- **新颖性**：首次将 RLHF/RLVR 思想引入自回归图生成用于 MAS 拓扑设计，直接优化“稀疏且正确”的联合目标。
- **奖励设计合理**：将正确性权重（0.6）显著高于结构紧凑性（0.3+0.1），确保不会为了省 token 而牺牲准确率。
- **数据复用机制**：重复利用 ARG-Designer 已有的执行数据，降低数据收集成本。
- **工程实用性**：Best-of-N 由轻量级奖励模型执行，额外开销小；支持单卡 GPU 部署，硬件门槛低。
- **严谨性**：采用 Welch's t-test 检验差异显著性，避免仅凭均值差下结论。

## 8. 不足与局限

- **对 LLM 骨干的依赖**：所有实验仅使用 Qwen3-4B，换用其他 LLM 时效果可能不同；且训练数据的标注依赖特定底模，更换底模需重构数据集。
- **不支持异构 MAS**：方法假设所有智能体使用同一 LLM，未能处理不同智能体使用不同模型的场景。
- **依赖真值标签**：仅适用于可验证答案的任务（数学、分类、代码生成），无法直接扩展到开放式、无真值标签的任务。
- **降本幅度有限**：仅减少约 20% 的 token，与静态单模型相比仍存在较大开销（如 GSM8K 的 token 仍为 Vanilla 的 17 倍左右），效率优化还有很大空间。
- **消融实验覆盖不全**：仅 3 个数据集上做消融，且未深入讨论各超参数（如奖励权重、δ、KL 系数）的敏感性。
