## 摘要
多模态检索增强生成（RAG）是面向视觉丰富长文档理解的关键技术。现有的多模态RAG方法正逐步向多智能体系统发展：它们首先根据查询检索相关页面，然后迭代理解这些页面内的信息。然而，这些方法通常依赖固定工作流，缺乏在测试时动态扩展计算的能力，往往导致证据不充分。为解决这一问题，我们提出D2-ScaleAgent，一个引入双维缩放范式的智能体框架，用于检索与推理。D2-ScaleAgent的核心是一个由验证器（Verifier）智能体驱动的动态路由循环，基于查询的内在难度，以持续更新的证据库为中心，该证据库作为智能体的动态工作记忆：当需要扩展检索时，智能体向外路由（检索缩放），将查询分解为属性并执行并行页面检索，随后通过自适应剪枝确保证据覆盖全面。当需要细粒度推理时，智能体向内路由（推理缩放），动态选择不同粒度和数量的子智能体从页面中提取证据。最后，D2-ScaleAgent在证据链上实现逻辑闭合。大量实验表明，D2-ScaleAgent在MMLongBench-Doc、LongDocURL等长且视觉丰富的文档基准上表现有效。

## Abstract
Multi-modal retrieval-augmented generation (RAG) is a key technique for visually rich long document understanding. Existing multi-modal RAG methods are progressively advancing toward multi-agent systems: they first retrieve relevant pages based on a query, and then iteratively understand information within those pages. However, these methods typically rely on fixed workflows and lack the ability to dynamically scale computation at test time, often leading to insufficient evidence. To address this, we propose D2-ScaleAgent, an agentic framework that introduces a dual-dimensional scaling paradigm for retrieval and reasoning. The core of D2-ScaleAgent is a Verifier agent-driven dynamic routing loop based on the intrinsic difficulty of the query, centered around a continuously updated evidence bank that serves as the agent's dynamic working memory: when retrieval needs to be expanded, the agent routes outward (retrieval scaling), decomposing the query into attributes and performing parallel page retrieval, followed by adaptive pruning to ensure comprehensive evidence coverage. When fine-grained reasoning is required, the agent routes inward (reasoning scaling), dynamically selecting sub-agents with varying granularity and count to extract evidence from pages. Finally, D2-ScaleAgent achieves logical closure over the evidence chain. Extensive experiments demonstrate that D2-ScaleAgent is effective on long and visually rich document benchmarks like MMLongBench-Doc, LongDocURL, etc.

## 1. 核心问题与整体含义
- **研究动机**：面向视觉丰富的长文档（如财务报告、科研论文）问答是重要应用，但大型视觉语言模型（LVLM）受限于上下文窗口，难以同时满足细粒度视觉细节与长文本需求。
- **现有方法不足**：主流思路包括多模态 RAG（先检索页面再细读）和多智能体/迭代机制（多步分析推理），但它们通常依赖**固定工作流**，缺乏根据查询难度在测试时动态扩展计算的能力，容易导致“证据不足”。
- **核心问题**：作者将长文档理解失败的根源归结为“**证据不足问题**”，并细分为两类：
  - **广度不足（Breadth Insufficiency）**：检索范围覆盖不完整，需向外扩展；
  - **深度不足（Depth Insufficiency）**：对局部内容理解浮于表面，需向内深挖。
- **整体含义**：长文档理解不应走固定流水线，而应像人类读者一样，根据证据缺口动态决定“向外找更多页面”还是“向内细读已有内容”，由此提出**双维缩放（Dual-Dimensional Scaling）**范式。

## 2. 方法论：D2-ScaleAgent
### 2.1 总体框架
- 核心是 **Verifier 代理驱动的动态路由闭环**，围绕一个持续更新的 **证据库（Evidence Bank）** 展开，作为系统的动态工作记忆。
- 证据库在全局步骤 t 的形式化状态为：
  `Bt = {E^page_t, E^region_t, E^atomic_t, s^comp_t, g_t}`，分别表示页面级、区域级、原子级证据，完整性分数，以及当前证据缺口。

### 2.2 属性引导的检索缩放（向外扩展）
- **查询属性分解**：将原始查询 q 分解为加权多视角属性查询集合 `Q = {(q0,w0), (q1,w1), …}`，包含核心意图和派生属性视角。
- **多轮候选累积**：依次为每个属性查询执行检索，得到局部候选集 R(m)，并不断并入全局候选池 `C(j)`。
- **基于排名的加权融合**：由于不同属性查询的检索分数不可直接比较，采用排名加权融合分数：
  `S_j(c) = Σ_{m=0..j} 1[c∈R(m)] * w_m / (κ + r(m)(c))`，其中 r(m)(c) 为页面 c 在第 m 次查询结果中的排名，κ 为平滑常数。
- **自适应剪枝与收敛**：
  - 用相对阈值 α 提取高价值证据集 `E^ret_j = {c ∈ C(j) | S_j(c) ≥ α S_j_max}`；
  - 用跨轮稳定性 `Stab_j = |E^ret_j ∩ E^ret_{j-1}| / |E^ret_j|` 判断检索是否饱和；
  - 当稳定性超过阈值 τ 时，自动终止检索扩展，而不是预先固定 Top-K 或轮数。

### 2.3 缺口感知的推理缩放（向内扩展）
- 采用三层成本分级的认知子代理，由路由机制按证据缺口动态选择：
  - **Global Surveyor（低成本页面理解）**：对候选页面集做宏观扫描，输出页面级证据 e^page_t；
  - **Region Locator（中成本区域聚焦）**：从宽泛候选集中定位关键区域（如表格），生成结构化摘要，输出高相关页面子集和区域级证据；
  - **Fine-grained Extractor（高成本原子提取）**：针对关键区域，按动态生成的提取规格进行高分辨率细读，提取可验证的原子事实。
- **证据更新**：各粒度证据增量式追加到全局集合，形成状态转移：
  `B_{t+1} = Update(B_t, e^page_t, e^region_t, e^atomic_t)`。

### 2.4 Verifier 代理驱动的路由与终止
- 每个推理步 t，Verifier 评估证据库的认知完整性，输出完整性分数和具体证据缺口：`(s^comp_t, g_t) = f_ver(q, B_t)`。
- 根据缺口类型动态路由：
  - **向内挖掘**：当已有页面但细粒度事实不足时，从推理工具包中选择 `fsur / floc / fext` 中的一个操作，继续细化；
  - **向外扩展**：当缺少基础来源页面时，将证据缺口转化为新检索意图，触发新一轮检索缩放。
- **终止条件**：当 `s^comp_t ≥ δ` 且 `g_t = ∅` 时，停止迭代，并基于逻辑闭合的证据库生成最终答案，避免在证据不足时强行输出导致幻觉。

## 6. 主要结论与发现
- D2-ScaleAgent 在平均端到端 QA 准确率上显著优于已有 RAG 和固定工作流多智能体基线（如 GPT-4o 上 63.7 vs MDocAgent 58.3）。
- 检索性能（Recall、Precision、nDCG、MRR）也全面超过 MoLoRAG，说明属性分解+迭代扩展比静态 Top-K 更有效。
- 消融研究表明：
  - **去掉 Verifier 代理驱动的闭环导致准确率下降最大**（52.0 → 44.1），说明证据验证和动态路由是系统核心；

- 案例研究显示，系统能够通过 Verifier 识别缺失链路，先外扩检索找到缺失页面，再内挖细读关键区域，最终完成跨页合成推理，证明检索与推理的“协同”比二者单独强化更重要。
