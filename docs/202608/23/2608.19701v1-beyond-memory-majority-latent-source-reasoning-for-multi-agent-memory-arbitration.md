## 摘要
长期多智能体系统会不断积累由不同智能体产生的记忆。现有记忆方法通常将检索到的记忆视为独立证据，并通过投票或加权进行组合。然而，这种独立性假设在多智能体场景中往往不成立：由不同智能体写入的记忆可能继承了相同的上游来源或共享偏差，导致相关证据被重复计数，从而形成虚假多数。我们将这种故障模式称为“记忆相关性偏差”。为解决这一问题，我们提出了相关性感知记忆仲裁（CAMA）框架，该框架联合解耦检索到的记忆并恢复缺失的独立证据。我们将检索到的记忆建模为查询条件下的证据组，并结合神经依赖推理与基于来源的符号先验来估计独立证据源的有效数量，从而防止相关记忆形成虚假多数。由于关键的独立证据可能不在初始检索集中，CAMA进一步学习了一种顺序恢复策略，在做出最终决策之前主动检索替代证据或追溯上游来源，旨在恢复足够的独立证据以实现可靠的仲裁，同时最小化检索成本。在多个基准上的实验表明，我们的方法优于最先进的基线方法，抑制了由相关记忆引发的虚假多数。

## Abstract
Long-term multi-agent systems continuously accumulate the memories produced by different agents. Existing memory methods typically treat retrieved memories as independent evidence and combine them through voting or weighting. However, this independence assumption often fails in multi-agent settings: memories written by different agents may inherit the same upstream source or shared bias, causing correlated evidence to be repeatedly counted and creating a false majority. We term this failure mode \textit{Memory Correlation Bias}. To address the issue, we propose the \textbf{C}orrelation-\textbf{A}ware \textbf{M}emory \textbf{A}rbitration (CAMA) framework that jointly decouples retrieved memories and recovers missing independent evidence. We model the retrieved memories as query-conditioned evidence groups and combine neural dependency inference with provenance-based symbolic priors to estimate the effective number of independent evidence sources, thereby preventing correlated memories from forming a false majority. Since critical independent evidence may be absent from the initial retrieval set, \textsc{CAMA} further learns a sequential recovery policy that actively retrieves alternative evidence or traces upstream sources before making the final decision, aiming to recover sufficient independent evidence for reliable arbitration while minimizing retrieval cost. Experiments on multiple benchmarks demonstrate the superiority of our method over the state-of-the-art baseline methods, suppressing false majorities induced by correlated memories.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究对象**：长期多智能体系统（LLM-based multi-agent systems），多个智能体在长时间跨度中持续写入观察、摘要、推理结果到共享持久化记忆中。
- **核心问题**：现有方法通常假设检索到的记忆是**独立证据**，通过投票或加权进行聚合。但在多智能体场景中，这一假设频繁失效——不同智能体的记忆可能继承同一上游来源或共享偏差，导致**相关证据被重复计数**，个别证据因素被多次表征，形成“虚假多数”（false majority）。作者将此故障模式命名为**记忆相关性偏差（Memory Correlation Bias）**。
- **危害**：一旦虚假多数决定了仲裁结果，错误结论会被写回共享记忆，进一步放大相关信号，造成持续、自我强化的错误循环，严重影响后续决策。
- **关键研究问题**：长期多智能体系统应如何依据“有效独立证据”而非“可见计数”来仲裁冲突记忆？

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 整体框架：CAMA（Correlation-Aware Memory Arbitration）

- 采用“查询条件下证据解耦 + 因子级仲裁 + 主动恢复”的联合框架，流程包括四个核心模块。

### 2.2 查询条件下的证据解耦（Query-Conditioned Evidence Decoupling）

- **核心思想**：将检索到的记忆建模为潜在证据槽（latent evidence slots），推断软记忆-槽分配矩阵，识别共享潜在证据因素。
- **神经符号证据分配**：使用集编码器（self-attention）联合建模查询、记忆交互与来源结构，产生分配矩阵；来源关系作为符号先验注入注意力机制的偏置项。
- **有效独立证据估计**：基于分配矩阵估计每个证据槽的最强归属值，并采用 **Hill 多样性指数** 计算有效独立证据数 \(N_{eff}\)，避免相关记忆重复累积证据质量。

### 2.3 因子级冲突仲裁（Factor-Level Conflict Arbitration）

- 对每个候选假设，在证据槽层面聚合支持分数，计算每个槽的支持度 \(\beta_j(h)\)。
- 结合源可靠性先验（直接观测性、历史可靠性、来源类型）计算槽级可靠性权重。
- 最终仲裁 logit 综合槽存在度、可靠性与支持度，经温度归一化输出假设后验概率。

### 2.4 主动独立证据恢复（Active Independent-Evidence Recovery）

- 将恢复建模为有限时域顺序决策过程，动作空间包括：
  - **Expand(q′)**：生成替代查询，检索额外独立证据；
  - **Trace(mi)**：沿来源关系追溯父记忆，揭示隐藏依赖；
  - **Stop**：终止恢复并返回当前仲裁决策。
- **终止条件**：有效证据数 \(N_{eff}\) 满足阈值且后验分布集中，或预算耗尽。

### 2.5 训练优化

- 使用 **actor-critic 强化学习** 优化恢复策略，奖励为终局决策正确性减去恢复成本。
- 联合训练三个目标：仲裁损失（\(L_{task}\)）、来源对比损失（\(L_d\)，弱监督利用来源关系）、RL 损失（\(L_{RL}\)）。
