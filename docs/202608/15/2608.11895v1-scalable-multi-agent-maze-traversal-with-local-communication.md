## 摘要
洞穴网络、管道系统及类似的迷宫环境对未知环境下通信受限的多智能体导航构成了重大挑战。我们提出一种分布式算法，使智能体能够集体遍历未知且可能含环的图。智能体在指定起始节点依次进入，任务是在避免碰撞的同时定位并到达未公开的目标。它们通过局部通信协调，采用领导者-跟随者关系及领导者切换机制。在任何时刻，仅由一个智能体执行探索，该智能体运行单智能体迷宫求解器。我们证明该算法是完备的，其完工时间在智能体数量上渐近等价于最优全知策略，并推导出其时间与空间复杂度。多达625个智能体的仿真显示，随着智能体数量增加，平均总燃料消耗递减，并表明所提方法优于所有智能体独立执行单智能体求解器的朴素基线方法。

## Abstract
Cave networks, pipe systems, and similar maze-like environments pose significant challenges for multi-agent navigation in unknown settings with limited communication. We propose a distributed algorithm that enables agents to collectively traverse an unknown, possibly cyclic graph. Agents enter sequentially at a designated start node and are tasked to localize and reach an undisclosed goal while avoiding collisions. They coordinate via local communication using leader-follower relationships and leader switching. At any moment in time, exploration is performed by only one of the agents, which runs a single-agent maze solver. We prove that the algorithm is complete, that its makespan is asymptotically equivalent (in the number of agents) to that of an optimal full-knowledge strategy, and derive its time and space complexity. Simulations with up to $625$ agents show a decreasing average sum-of-fuels as the number of agents increases and demonstrate that the proposed approach outperforms a naïve baseline in which all agents independently execute the single-agent solver.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：采用**领导者-追随者（leader-follower）**层级结构。**
  - 在任意时刻，只有一个智能体（称为**头节点/Head**）负责执行单智能体迷宫求解器来探索环境；
  - 其余智能体通过选择邻接或两跳内的智能体作为“领导者”，形成以头节点为根的**入树（in-tree）**结构，从而间接跟随头节点移动；
  - 当移动发生冲突时，通过**领导者切换**机制让角色在智能体间传递，保证探索持续推进而不会死锁或碰撞。
- **关键技术细节**：
  - **局部通信模型**：智能体可与同节点、相邻节点，或间隔一个空节点的两跳距离内的智能体通信，通信不能穿过被占用节点。消息类型包括：
    - **状态消息**：每时间步广播，包含 ID、是否位于目标、领导者指针；
    - **竞争消息**：非头节点广播其是否参与竞争移动；
    - **头消息**：头节点广播，包含求解器状态、下一步目标以及新头节点 ID。
  - **冲突避免机制**：通过 `ResolveConflict` 流程解决争夺同一节点的问题。多个追随者竞争其领导者上一时刻所在节点时，使用确定性 `Selector`（按固定 ID 顺序）选出胜者；胜者移动到该节点，败者转为以胜者为新领导者，从而维持通信连通性且避免碰撞。
  - **单智能体求解器可替换**：算法允许使用任意完备的单智能体迷宫求解器作为底层的“探索引擎”，论文中使用 Trémaux 算法、BFS 和均匀随机游走三种求解器进行验证。
- **算法流程（文字描述）**：
  1. 初始化：所有智能体在起始节点；第一个激活的智能体成为头节点，其余智能体依次激活，并选择离开起始节点的智能体作为领导者。
  2. 每轮时间步内：
     - 头节点运行单智能体求解器得到候选移动节点；若目标节点已被占据，则将被占据者选举为新头节点，并广播头消息；
     - 非头节点执行 `ResolveConflict`：若头节点在通信范围内，则等待头消息并响应；否则判断是否可移向目标、是否需竞争领导者上一节点；
     - 所有智能体同步移动到各自目标节点，然后更新状态并发送消息。
  3. 当有智能体到达目标节点后，它停止发送消息，但仍作为其他智能体的领导者（若被跟随），引导后续智能体逐个抵达目标。
- **关键理论结果**：
  - **Lemma 1**：任意时刻有且仅有一个头节点；
  - **Lemma 2**：任何非起始节点首次被访问必然由头节点完成；所有智能体通过同一相邻节点到达目标；
  - **Lemma 3**：任意非目标节点在同一时刻最多被一个活动智能体占据，且不存在顶点冲突或跟随冲突；
  - **Lemma 4-5**：领导者-追随者图始终是连通入树，通信范围保持连接；
  - **Theorem 1**：若单智能体求解器在时间 $k_g - 1$ 首次访问目标相邻节点，则 $n$ 个智能体最迟在 $k_g + 2(n-1)$ 个时间步内全部到达目标；
  - **Theorem 2**：算法 makespan 与全知最优策略相比，要么相等，要么随 $n$ 增大**渐近等价**（$\lim_{n\to\infty} R(n) = 1$）；
  - **复杂度**：空间复杂度为 $O(d\min(n, d^2))$（$d$ 为图最大度数，$n$ 为智能体数），额外取决于单智能体求解器；时间复杂度依求解器不同，如 Trémaux 为 $O((|E|+n)\min(n,d^2))$，BFS 为 $O(((|V|+|E|)^2 + n)\min(n,d^2))$，随机游走期望为 $O((|V|^3 + n)\min(n,d^2))$。

- **算法完备性**：只要底层单智能体求解器完备，所提出的 MAMT 算法保证所有智能体在有限时间内到达目标。
- **渐近最优性**：makespan 与全知最优策略随智能体数量 $n$ 的比值趋近于 1，即在大量智能体场景下接近理论最优性能。

- **性能趋势**：
  - 随着智能体数量增加，**平均总燃料消耗显著降低**，因为一旦头节点发现目标，后续智能体通过跟随领导者能以较短路径到达；

  - MAMT 在均值和最坏情况上均优于朴素基线，尤其在智能体数量较多时优势明显（朴素基线在 625 个智能体时频繁超时）。
