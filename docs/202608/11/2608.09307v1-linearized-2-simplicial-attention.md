## 摘要
我们通过将三线性得分重写为复合查询与键的内积，提出了一种线性化的2-单纯形注意力形式，使得在一个令牌轴上的求和与普通softmax注意力的形式相同。然后我们使用正随机特征来近似这个求和，并将整个历史存储在一个固定大小的状态中，而第二个轴则在一个短窗口内的最近令牌上保持显式。这使我们能够在序列长度上实现线性成本，同时获得窗口化2-单纯形注意力所缺乏的全局覆盖范围。我们使用自定义的Triton内核实现它，并将其与Kimi Delta注意力结合，构建了一个完全没有softmax注意力的模型。在匹配的计算条件下，该模型在比较的架构中实现了最高的平均下游准确率，并且在16k上下文下，它相比KDA混合模型提高了平均准确率，同时将LAMBADA困惑度从715.6降低到602.6。

## Abstract
We present a linearized form of 2-simplicial attention by rewriting the trilinear score as an inner product between a composite query and a key, so that the sum over one token axis takes the same form as ordinary softmax attention. We then approximate this sum with positive random features and store the entire past in a fixed-size state, while the second axis stays explicit over a short window of recent tokens. This enables us to achieve linear cost in sequence length combined with a global reach that windowed 2-simplicial attention lacks. We implement it with custom Triton kernels and combine it with Kimi Delta Attention to build a model with no softmax attention at all. Under matched compute, this model achieves the highest mean downstream accuracy among the compared architectures, and at 16k context it improves mean accuracy over a KDA hybrid while lowering LAMBADA perplexity from 715.6 to 602.6.

## 一、核心问题与整体含义

**研究动机：**
- 2-单纯形注意力（2-Simplicial Attention）能够捕捉查询与两个历史token之间的三元高阶交互，理论上对某些任务（如三变量检测）具有比标准注意力更强的表达能力。
- 但原始的2-单纯形注意力计算复杂度为 **O(T³)**（查询对整个二维token对平面做softmax），实际应用受限。
- 已有的窗口化2-单纯形注意力（如Roy等人提出的精确窗口实现）虽然把复杂度降到可接受范围，但**丧失了全局感受野**——历史信息只在局部窗口内可见。
- 核心问题：**能否在获得全局可达性的同时保持线性计算复杂度？**

**整体含义：**
这篇文章提出了一种线性化的2-单纯形注意力（LinSimp），通过正随机特征（positive random features）近似将token历史压缩为固定大小的线性注意力状态，同时保留近期token的显式锚点窗口。该方案以线性成本实现全局历史访问，并能与Kimi Delta Attention（KDA）组合成完全无softmax注意力的模型。在匹配计算预算下，该模型在多个基准上取得有竞争力的下游准确率。

## 二、方法论

### 2.1 核心思想

**三线性分数的重写（One-Mode Kernelization）：**

原始的2-单纯形注意力使用三线性分数：
```
s_ijc = ⟨τ·q̂ᵢ, k̂ⱼ, r̂c⟩ = ⟨(τ·q̂ᵢ) ⊙ r̂c, k̂ⱼ⟩
```
论文的关键洞察是：对固定的查询i和锚点c，**三线性分数可以写成复合查询z_ic = (τ·q̂ᵢ) ⊙ r̂c 与键 k̂ⱼ 的内积**，从而将沿j轴的求和变为普通softmax注意力中指数点积核的形式。

### 2.2 正随机特征近似

- 定义正特征映射 φ(x) = (1/√m)·exp(Ωx − ‖x‖²/2·1)，其中 Ω ∈ R^{m×D} 是随机高斯矩阵。
- **引理1**：E_Ω[φ(x)ᵀφ(y)] = exp(xᵀy)，即该特征映射无偏估计指数点积核。
- 使用正交随机特征块（正交高斯边际 + 卡方行范数），降低估计方差；最终包含QR分解的符号校正，使估计误差随m⁻¹/²下降。

### 2.3 前缀状态的固定大小存储

将全局token索引j的求和收集为两个前缀状态：
- Mᵢ = Σ_{j≤i} φ(k̂ⱼ)vⱼᵀ ∈ R^{m×D_v}（递归更新：Mᵢ = Mᵢ₋₁ + φ(k̂ᵢ)vᵢᵀ）
- aᵢ = Σ_{j≤i} φ(k̂ⱼ) ∈ R^m（递归更新：aᵢ = aᵢ₋₁ + φ(k̂ᵢ)）

这样，整个过去历史的检索成本为**O(1)（与序列长度无关）**。

### 2.4 锚点窗口

- 为避免在锚点c轴上做全局求和（那样仍为二次复杂度），仅保留最近的**w=64**个锚点：Cᵢ = {max(1, i−w+1), ..., i}。
- 每个近期锚点构成不同的复合查询z_ic，发送到同一全局前缀状态，因此**任意远处的token仍可以被检索**。

### 2.5 最终输出形式

```
Nᵢ = Σ_{c∈Cᵢ} (φ(z_ic)ᵀMᵢ) ⊙ u_c
Zᵢ = Σ_{c∈Cᵢ} φ(z_ic)ᵀaᵢ
oᵢ = Nᵢ / (Zᵢ + ε)
yᵢ = g · RMSNorm(oᵢ)，g = σ(γ)（可学习标量门控）
```

- **定理1**：对固定特征秩m和锚窗口w，该层是因果的，总复杂度为 **O(T · w · m · (D+D_v))**，即随序列长度线性；自回归推理状态大小为 O(mD_v + m + w(D+D_v))，独立于T。

### 2.6 数值稳定与核实现

- **Log空间评估**：在线更新所有锚点/特征行上的最大值L作为稳定漂移量，同时缩放分子分母（共同因子在比率中精确消去），保证因果性（不使用未来信息的全局最大值）。
- **自定义Triton内核**：前向使用32-token分块和独占边界状态重构；反向采用两遍扫描（query并行 + chunk并行），避免存T×m×D_v张量。
- **核性能**：B=8、seq=2048、m=128、w=64时，单层前向+反向为37ms，约为softmax注意力层的1.03倍。

## 八、不足与局限

1. **统计效力不足**：所有实验为单一种子，无方差估计/置信区间，结论的稳健性存疑。
2. **规模限制**：模型仅~330M参数，训练token最多3.14B，论文也承认“扩展行为未知”，无法推断更大规模下的表现。
3. **内核性能说服力有限**：当前内核只是“功能性实现”，反向传播有大量重复计算，尚未达到比softmax更快的目标；这使得“线性复杂度”在实际吞吐上的优势未兑现。
4. **iso-FLOP是解析估计**：与实际能量、延迟、系统总成本无直接对应。
5. **锚点窗口的语义限制**：虽然全局检索可达，但每次检索都受锚点c的“调制”——近期锚点决定“问什么问题”，全局状态负责“检索”。理论上，依赖两个远历史token的交互可能无法被有效表达（除非它们通过状态表示间接体现）。
6. **无任务层面的分析验证**：论文没有针对性评估三元高阶交互能力（如三元检测任务、系统泛化基准），无法确认改进是否真的来源于高阶交互机制的增强。
7. **评估维度窄**：下游任务集中在常识问答/阅读理解类；未覆盖代码、多语言、数学推理的细粒度评估（虽然训练用了数学数据）。
8. **时间范围提示**：论文标注2026年8月arXiv提交，实验基于较早的Kimi/KDA版本，与后续SOTA的差距需要更新对比。
