## 摘要
大型语言模型多智能体系统（LLM-MAS）依赖智能体间的通信来解决复杂推理任务，然而关于共识性能与计算资源之间严格保证的研究仍然有限。在此，我们提出了一种新颖的方法，将集体信念动态表征为离散时间切换系统，其中通信拓扑具有不同的共识收缩率和代币成本。通过将剩余计算预算纳入信念动态，我们定义了一个同时捕捉一致性和资源可行性的共识安全集。我们推导了共识时间和代币消耗的显式界限，并构建了一个共识-预算证书区域，确保在资源耗尽的情况下实现有限时间收敛。我们进一步建立了自适应拓扑切换相对于固定拓扑策略在收敛速度与通信成本之间实现权衡的条件。数值实验和实时LLM-MAS部署展示了预测的共识-成本权衡，证明了控制论证书如何实现AI系统中的资源感知协调。

## Abstract
Large language model multi-agent systems (LLM-MAS) rely on inter-agent communication to solve complex reasoning tasks, yet rigorous guarantees relating consensus performance to computational resources remain limited. Here, we present a novel way to characterize collective belief dynamics as a discrete-time switched system in which communication topologies have distinct consensus-contraction rates and token costs. By augmenting the belief dynamics with the remaining computational budget, we define a consensus safe set that jointly captures agreement and resource feasibility. We derive explicit bounds on consensus time and token expenditure and construct a consensus-budget certificate region guaranteeing finite-time convergence without resource exhaustion. We further establish conditions under which adaptive topology switching achieves a trade-off between convergence speed and communication cost relative to fixed-topology strategies. Numerical experiments and live LLM-MAS deployments show the predicted consensus-cost trade-offs, demonstrating how control-theoretic certificates can enable resource-aware coordination in AI systems.

## 1. 核心问题与研究动机

- **背景**：大语言模型多智能体系统（LLM-MAS）通过智能体之间的通信协作完成复杂推理任务，但其每一步通信都消耗 token 等计算资源，而机器学习社区对“共识性能与资源消耗之间”的关系缺乏严格的理论保证。
- **核心问题**：在有限 token 预算下，如何**保证**多智能体的集体信念状态能在**资源耗尽之前**收敛到 ε-共识（即足够接近的平均共识），避免由于预算不足导致的推理失败。
- **动机**：LLM 推理成本巨大（水、电、token 开销），且在 agentic AI 中，多轮推理、工具调用和智能体通信加剧了资源压力。现有工作偏重经验性系统，缺乏形式化的安全证书（safety certificate）来保证共识与预算的可行性。

## 2. 方法论

- **整体框架**：将 LLM-MAS 建模为**离散时间切换系统**，通信拓扑作为切换模式，由监督控制器（harness）根据当前分歧程度选择激活哪种图拓扑。
- **核心变量与定义**：
  - 每个智能体持有 d 维信念向量 \(x_i(k)\)，系统集体状态为矩阵 \(X_k \in \mathbb{R}^{N\times d}\)。

  - 分歧程度 \(D(k)=\frac{1}{\sqrt{N}}\|P X_k\|_F\)，其中 \(P\) 为到分歧子空间的投影矩阵。
  - token 预算动态：\(b_{k+1}=b_k-c_{\sigma_k}\)。
- **切换策略（范数阈值切换）**：当 \(D(k)>\eta\) 时激活稠密模式（如全连通图，高成本快收敛），当 \(D(k)\le\eta\) 时切换到稀疏模式（如环形图，低成本慢收敛）。
- **安全集与证书区域**：
  - \(\epsilon\)-共识安全集 \(\Omega_\epsilon=\{(X,b): D(X)\le\epsilon, b\ge0\}\)。
  - 共识-预算证书区域 \(\Omega_{\text{cert}}=\{(X,b): b\ge B^*(D(X))\}\)，其中 \(B^*(D)\) 给出所需最小预算的显式表达式。
- **定理性结果**：
  - **定理 1**：给出收敛轮数上界 \(K_1, K_2, K^*\) 及总成本 \(B^*\) 的闭式公式。
  - **定理 2**：若初始状态 \((X_0,b_0)\in\Omega_{\text{cert}}\)，则能在 \(K^*\) 轮内到达 \(\Omega_\epsilon\)，且预算不会耗尽。
  - **推论 1**：当满足一定条件时，自适应切换策略在速度和成本上同时优于“仅环形”和“仅全连通”的单拓扑策略（Pareto 折衷）。
