## 摘要
多智能体LLM系统越来越多地用于辩论答案、协调研究、模拟用户和调解信息流，使得智能体间的说服成为一种基本但未被充分衡量的能力。我们引入了一个受控测试平台，用于研究目标导向的说服者如何在基于真实世界自我中心网络拓扑的LLM智能体网络中改变引发的立场。通过四个LLM骨干、五个图谱和55个政策声明，我们发现说服动态取决于拓扑、竞争、主题和模型先验之间的相互作用。此外，我们表明，在竞争运行中，直接接触可靠地预测下一轮立场变化，而同伴中继传递较小但可测量的影响，表明未被指定说服的智能体仍能传递说服力。最后，仅分析帖子文本会遗漏重要动向：计划策略仅在执行消息中部分实现，行动选择可能与消息内容不同，而受说服者很少陈述探针检测到的立场转变。这些结果主张将多智能体说服评估为轨迹和暴露层面的过程，使用信念探针、暴露来源和行动日志来识别谁影响了谁，以及可见语言是否反映了潜在的立场变化。

## Abstract
Multi-agent LLM systems increasingly debate answers, coordinate research, simulate users, and mediate information flows, making agent-to-agent persuasion a basic but undermeasured capability. We introduce a controlled testbed for studying how goal-directed persuaders shift elicited stances in networks of LLM agents grounded in real-world ego-network topologies. Across four LLM backbones, five graphs, and 55 policy statements, we find that persuasion dynamics depend on the interaction between topology, competition, topic, and model prior. Additionally, we show that direct exposure reliably predicts next-round stance change in competing runs, and peer relays carry smaller but measurable influence, showing that agents not assigned to persuade can still transmit persuasive force. Finally, analyzing post text alone misses important movement: planned strategies are only partly realized in executed messages, action choices can diverge from message content, and persuadees rarely state the stance shifts detected by probes. These results argue for evaluating multi-agent persuasion as a trajectory- and exposure-level process, using belief probes, exposure provenance, and action logs to identify who influenced whom and whether visible language reflects underlying stance movement.

## 1. 核心问题与整体含义

**研究动机：**
- 多智能体LLM系统正被广泛用于辩论答案、协调科研、模拟用户和调解信息流，使智能体间**相互说服**成为一项基本但**未被充分量化**的能力。
- 说服能力具有双面性：既能帮助智能体纠正错误假设、协调共识，也可能被恶意利用，在网络中放大操纵性叙事（Schroeder et al., 2026）。
- 现有研究多关注LLM向**人类**的说服效果，而**智能体对智能体**的网络化说服动态仍属空白。
- 网络不是简单的"更大规模的对话"：它决定了谁看到哪些信息、谁能中继信息、观察到的立场变化源自直接说服、同伴放大还是竞争叙事。
- 单一最终答案容易受措辞和短暂上下文影响（Hase et al., 2021；Kabir et al., 2025），因此需要在固定探针下逐轮追踪信念轨迹。

**整体含义：**
- 说服（persuasion）应被视为多智能体系统（MAS）的基本原语（primitive），其安全目标应该是**信念传播（belief propagation）**，而非仅确保消息投递。
- 评估多智能体说服必须从**轨迹层面（trajectory-level）**和**暴露层面（exposure-level）**进行，使用信念探针、暴露溯源和行动日志识别"谁影响了谁"以及"可见语言是否反映潜在立场变化"。

## 2. 方法论

### 2.1 核心思想
构建一个**受控研究平台**（controlled testbed），将LLM智能体嵌入真实世界的ego网络拓扑，允许它们通过有限的动作词汇进行社交互动，并在每轮固定探针下重复测量信念变化。

### 2.2 关键设计要素

| 要素 | 说明 |
|------|------|
| **角色区分** | 说服者（PR）固定信念端点，被说服者（PE）随暴露更新信念 |
| **两种设置** | `singlePR`（单一说服者，信念钉在1.0）与`dualPR`（两个说服者，PR1=1.0、PR2=0.0） |
| **初始信念** | 通过**个性化PageRank（PPR）**在图结构上计算，不依赖手写人格设定；singlePR用min–max缩放到[0.1, 0.9]，dualPR用两源PPR得分占比（share-of-mass） |
| **信念测量** | 7点李克特式多选题（7-MCQ）的**token概率加权均值**：$b_i = \frac{1}{6}\sum_{k=0}^{6} k p_k$，保留不确定性而非坍缩为单一选项 |
| **动作词汇** | 九种社交动作：create_post、comment、repost、quote、like、report、follow、unfollow、noop |
| **两阶段行动生成** | 先调用LLM生成计划理由（plan_rationale），再生成动作列表（action_rationale + action），分离"意图"与"执行" |

### 2.3 算法/流程细节
- **每轮循环（共T=10轮）**分四个固定阶段：
  1. **PR阶段**：说服者先行动，生成新内容；
  2. **PE阶段**：被说服者在冻结的轮初快照上并行决策（防止PE间同轮级联混淆PR消息效果与执行顺序）；
  3. **信念检查**：对每个PE执行token概率探针，PR跳过检查并保持端点信念；
  4. **轮次总结**：记录暴露计数、动作计数和信念快照。
- **信息源归因**：每个暴露事件记录作者、接收者、投递机制（follow/algorithmic）和PR影响链，将直接暴露与同伴中继（peer-mediated）暴露分离。
- **回归分析**：$\Delta b_{i,t} = \alpha + \sum_{c \in C} \beta_c x_{i,t,c} + \epsilon_{i,t}$，以OLS+异方差稳健标准误（White, 1980）估测**每次额外暴露**与下轮信念变化的关系。

## 6. 主要结论与发现

### 6.1 结果一：网络密度并非统一加速器
- **singlePR下**，稠密图G3使PE向说服者移动的比例下降17–52%（如GPT-4o为22.2% vs. 73.9%）；
- **dualPR下**，G3反而使向PR1移动的比例上升9–16%（密度效应**符号翻转**）。
- 结论：密度是"机制放大器"（regime amplifier）而非扩散的线性加速器。

### 6.2 结果二：竞争改变轨迹吸引子
- 不同设置下轨迹**靠近模型先验的程度**不同：singlePR使主题均值远离先验、趋向说服者；dualPR使终点更贴近模型先验。
- 主题相对排序（文化/社会规范低、气候/经济政策高）在4个骨干间稳定；但具体数值因模型而异。
- Gemini-2.5-Pro设置差异最大；GPT-4o早升后平台化；GPT-4.1与Gemini-2.5-Flash单调上升、主题分散度更大。

### 6.3 结果三：竞争改变主导PE轨迹形态
- singlePR最大单元为 converted_pro（53.4%）；dualPR下质心移向 converted_con（17.1%），con终带从4.5%增至25.5%，**tug_of_war（中立起点的震荡）**成为主导形态（57.8%，约为singlePR的3倍）。
- 四个骨干均复现两个关键特征；Gemini-2.5-Pro的tug_of_war最高（69.6%）。

### 6.4 结果四：直接暴露主导、同伴中继可测量
- **dualPR**：所有骨干上直接暴露PR1为正、PR2为负，符号一致，幅度仅跨模型变化2.5倍；累计效应每侧达+0.16~+0.26（PR1）/ −0.22~−0.32（PR2）。
- **同伴中继**虽小但显著（尤其PR2侧，全部4骨干显著），Gemini-2.5-Pro上中继与直接暴露相当（−0.0053 vs. −0.0050）。
- **singlePR**：直接暴露系数近零、跨骨干符号不稳定——单一说服者场景下逐暴露关联弱。

### 6.5 结果五：计划策略与执行文本存在系统性脱节
- 仅**72.7%**的计划Cialdini原则出现在执行文本中；social_proof（计划84.8%→文本49.6%）和commitment（90.2%→74.7%）下降最大；非文本动作（like/repost/follow）不携带缺失原则。
- 策略文本混合受**主题先验**影响大于设置或模型：authority从tech_ai_policy的81%到cultural_social_norms的7%，横跨11倍区间。

### 6.6 结果六：PE语言很少直接揭示信念移动
- 94.0%的PE消息在轮次2–3时与此前PR原则共享Cialdini标签（原则镜像），73%存在低度对冲（hedging），但明确的立场转换语言极少（0.18%反转、12.4%软化、0.11%硬化）。
- 仅分析post文本会**严重低估**心理移动量，必须依赖信念探针和暴露日志。

### 6.7 结果七：对多智能体系统的设计启示
1. **次级说服（secondary persuasion）**很普遍且构成安全风险——中继者（非说服者角色）可传递说服力；
2. **单个说服者**即可引发系统级信念扩散，风险不限于共谋；
3. **dualPR并非天然平衡**——反而可能加剧两极化与摇摆（tug-of-war）；
4. **说服常为非文本性**——点赞、转发、排序、来源选择、沉默都可能传递说服。

## 7. 优点

- **受控且可复制**：固定互动协议、动作词汇、信念探针，使变量归因清晰，4,400次运行的实验矩阵提供充分的统计效力。
- **创新测量方法**：使用**token概率加权7-MCQ探针**而非单一自由文本答案，保留不确定性且防止recency-driven迎合偏差；在固定描述下逐轮测量信念，避免一次性问卷的脆弱性。
- **归因清晰**：暴露日志记录直接/中继路径，回归模型分离直接说服与同伴放大，因果关联有鲁棒性检验。
- **多层机制分析**：意图层（计划）→ 执行层（文本）→ 行为层（动作）→ 心理层（探针信念）四层剥离，验证了"表面文本≠潜在信念"这一核心论断。
- **跨模型与跨主题验证**：4骨干、2模型家族、11主题域的系统变化确保结论非单模型或单主题偶然。
- **实际意义明确**：为MAS的安全评估提供了可操作的审计工具——信念轨迹、暴露溯源、行动日志；对防御性监测有直接指导意义。

## 8. 不足与局限

### 8.1 实验覆盖局限
- **图规模与类型受限**：仅5个18–42节点的ego-network，无法独立变化密度、聚类、模块性、同质性；缺少合成图控制的消融；未达到人口级社会模拟规模。
- **随机种子少**：仅2个RNG种子，轨迹形态百分比和策略构成份额应视为该运行集上的描述性估计，而非完整随机分布；小百分比差异不应过度解读。
- **模型与语言范围**：仅GPT-4o/4.1和Gemini-2.5-Flash/Pro四种英文模型，未覆盖其他模型家族、非英语语言、开放式动作空间或工具使用。
- **未与人类数据对照**：动态是否复现人类说服模式未经验证，外部效度不明。

### 8.2 偏差风险
- **先验与网络位置耦合**：PPR初始化导致初始立场与图位置在构造上相关，无法独立评估"网络位置效应"与"初始先验效应"；消解设计（随机/均匀先验）留待未来工作。
- **暴露归因是相关性**：作者明确说明暴露→信念效应为"受控关联"而非随机化因果效应，尽管M3规范加强了稳健性。
- **分类器的锚定风险**：Cialdini原则标注依赖GPT-5-mini分类器（尽管有87.3%人工验证准确率）；原则标签与文本的对应关系仍可能遗漏细微修辞。
- **探针局限性**：7-MCQ探针本身是测量工具，token概率分布不代表真实"认知状态"，可能是可操纵的表面信号。

### 8.3 应用限制
- 结果仅适用于"封闭环境中的固定动作词汇"设置，不能直接外推到真实平台（如X, Facebook）的开放交互；
- 模拟从未部署给真实用户，说服安全的结论需谨慎推广到在线实际系统；
- 55条政策声明均由人工编写，虽覆盖11域，但单一声明式措辞、主题选择和范围仍受作者设计偏差影响。
