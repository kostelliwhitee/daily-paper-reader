## 摘要
通信受限的分布式多智能体系统中的协作任务调度具有挑战性，因为每个智能体必须在满足复杂实际约束的同时，基于部分且动态的观测做出决策。现有启发式方法依赖手工设计的投标规则和重复共识，而许多基于学习的方法假设全局观测，缺乏基于显式通信的协调。为解决这些局限，本文提出一种用于分布式多机器人任务分配（MRTA）的神经调度框架，由多解码器图注意力模型（MDGAM）策略模型和无评论家组相对多智能体策略梯度（GRMAPG）训练算法组成。MDGAM使用扩展的图注意力机制联合更新节点和边特征，并采用多个解码器生成任务选择决策和通信消息。GRMAPG从等价任务规划实例中构建组相对优势，以替代传统MARL算法中使用的评论家网络，从而降低训练难度并提高收敛性能。在不同问题规模和通信范围下的实验表明，所提方法相对于现有启发式和基于学习的方法提高了任务完成性能，同时消融、复杂度和泛化测试进一步验证了所提出的创新。

## Abstract
Cooperative task scheduling in communication-constrained distributed multi-agent systems is challenging because each agent must make decisions from partial and dynamic observations while satisfying complex practical constraints. Existing heuristics rely on handcrafted bidding rules and repeated consensus, whereas many learning-based methods assume global observations and lack explicit communication-based coordination. To address these limitations, this paper proposes a neural scheduling framework for distributed multi-robot task allocation (MRTA), consisting of a multi-decoder graph attention model (MDGAM) policy model and a critic-free group relative multi-agent policy gradient (GRMAPG) training algorithm. MDGAM uses an extended graph attention mechanism to jointly update node and edge features, and employs multiple decoders to generate task-selection decisions and communication messages. GRMAPG constructs group-relative advantages from equivalent task-planning instances to replace the critic network used in conventional MARL algorithms, thereby reducing training difficulty and improving convergence performance. Experiments under different problem scales and communication ranges show that the proposed method improves task-completion performance over existing heuristic and learning-based methods, while ablation, complexity, and generalization tests further validate the proposed innovations.

## 一、核心问题与研究动机

**背景：** 分布式多智能体系统（机器人、车辆、无人机等）在智能交通、物联网、应急响应等场景中需协作执行空间分布的任务。多机器人任务分配（MRTA）旨在确定智能体的任务执行序列，以优化全局指标（如任务完成数、奖励、旅行成本）。

**核心挑战：**
- MRTA本质上是组合优化问题（NP-hard），且为多车辆路径规划问题的变体。
- **通信受限**：每个智能体仅能获取局部、时变的部分观测，需通过有限的通信链路与邻近智能体协调，通信拓扑随时间变化，甚至可能分裂为多个不连通组件。
- **复杂约束**：异构智能体属性（能力、速度、返回时间）、任务时间窗约束、服务时长要求、任务类型匹配等。

**现有方法局限：**
- **启发式方法**（CBBA、PI-maxAss、EEPI等）：依赖手工设计的投标函数或性能影响函数，在通信受限和时变局部观测下需要重复规划，导致大量通信与计算开销。
- **现有学习方法**（DL-DRL、CAM等）：多假设全局观测可用，或缺乏显式的通信协调机制；CAM虽学习分布式策略但未考虑时变通信拓扑。

**核心问题：** 如何在通信受限、只有局部观测的条件下，设计一个能够联合进行任务规划与智能体间协调的分布式调度策略，最大化总任务完成数。

## 二、方法论

### 问题建模（Dec-POMDP）
- 将分布式决策过程建模为去中心化部分可观测马尔可夫决策过程（Dec-POMDP）。
- **全局状态演化**：`s_{j+1} ~ P(s_{j+1} | s_j, a_j^{m_j}, c_j^{m_j})`，其中 `a_j^{m_j}` 为当前活动智能体的任务选择动作，`c_j^{m_j}` 为生成的通信消息。
- **策略输出**：任务选择概率分布 `a_j^{m_j} ~ P_θ(a_j^{m_j} | o_j^{m_j})` 和通信消息 `c_j^{m_j} = f_c^θ(o_j^{m_j})`。
- 决策过程是**异步事件驱动**的：每个智能体在完成任务服务后才触发新的决策事件。
- 优化目标为最大化终端总任务完成数的期望：`max_θ E[R(σ, g)]`。

### 核心方法一：MDGAM（多解码器图注意力模型）

**（1）扩展图注意力机制（核心创新之一）**

提出三种注意力操作联合更新节点与边表示：
- **Node-Node Attention**：聚合可观测节点的上下文信息，得到中间节点表示 `ĥ_i^ℓ`。
- **Edge-Node Attention**：利用边的两个端点节点表示更新边表示 `e_{ij}^ℓ`。引入方向感知的位置编码算子 `PE(·,·)` 来区分有向边的起点和终点（起点拼接标量-1，终点拼接标量+1），无需额外可学习参数。
- **Node-Edge Attention**：将边信息传播回节点表示 `h_i^ℓ`。

三者结合实现节点与边表示的双向信息交换，可处理非欧氏或非对称的转移代价。

**（2）编码器**
- 输入局部观测图包含：当前智能体自身、其基地、候选任务节点、通信可达的邻居智能体。
- 不同类型节点（own/dep/task/agent）使用类型特定的初始嵌入层投影。
- 边特征初始化为成对距离（经线性层投影），可扩展为更一般的转移代价。
- 堆叠 L=4 层编码器，每层含注意力模块（8头，d_q=d_k=d_v=16）和带残差的前馈模块（隐藏维度 256），使用层归一化。

**（3）任务解码器**
- 以当前智能体的编码表示作为初始决策上下文，通过 K1=1 层注意力更新。
- 单头注意力打分每个候选节点，采用 `α·tanh(·)` 缩放，不可行节点掩码设为 -∞，输出任务选择概率分布。
- 训练时采样、测试时贪心解码。

**（4）通信解码器**
- 结构类似任务解码器，但输出为连续的消息向量 `c_i^m = W_com·c^{K2} + b_com`。
- 消息维度 d_com=128，可被通信可达的其他智能体在后续决策事件中获取。

### 核心方法二：GRMAPG（组相对多智能体策略梯度，核心创新之二）

**动机：** 传统MARL算法（MAA2C、MAPPO）需要训练评论家网络，但存在两个问题：
1. 终端奖励在完整轨迹结束前不可得，步骤级奖励分配困难。
2. 额外评论家增加了参数量，且价值估计误差影响策略优化。

**关键思想：**
- 对每个问题实例 g，通过**等价变换**构造一个实例组 G(g) = {g_1, g_2, ..., g_K}（K=4），这些变换保持理论最优目标不变，包括：坐标旋转、任务类型与智能体能力对应交换、时间参数与速度的联合缩放等。
- 针对组内每个成员 g_k，策略生成联合轨迹 σ_k，获得终端奖励 R_k。
- 使用**留一法基线**：`b_k = (1/(K-1)) Σ_{j≠k} R_j`，组相对优势定义为 `Â_k = R_k - b_k`。
- 算法证明了该基线满足条件独立性，因此梯度估计保持无偏。

**优点：**
- 无评论家网络，减少可训练参数。
- 直接优化终端任务完成目标，避免手工设计步骤级奖励。
- 利用问题对称性构造的组间相互监督，提供较低方差的优势估计。
- 相比MAPPO/MAA2C有更好的训练收敛性能。

## 六、主要结论与发现

1. **主实验性能优越**：在所有9种组合下，MDGAM均取得最高平均完成数。以r=0.4为例，相对PI-maxAss提升2.24%~5.94%（随规模增大而增大），相对CAM提升2.86%~5.06%。
2. **通信范围影响**：更大的通信范围普遍提升所有方法的表现，但即使r=0.2的严格约束下，所提方法仍表现最佳。
3. **消融验证**：
   - 通信解码器带来稳定增益（约0.77~1.35个任务）。
   - 扩展图注意力优于AM和GCN（分别提升1.89~2.63和1.31~2.40个任务）。
   - GRMAPG优于MAPPO和MAA2C，收敛更快、最终性能更高。
4. **复杂度优势**：大规模下运行时间约 PI-maxAss 的1/95、EEPI的1/5.7；通信次数从5272（PI-maxAss）/3905（EEPI）降至2149。
5. **泛化能力**：
   - 对任务数变化最鲁棒（最大性能差距仅0.7%）。
   - 对智能体数变化，偏差≤2时退化<1%，偏差4时约3%。
   - 对通信范围变化，极端设置（r=0.2或0.6）训练的模型跨范围迁移较差，中间范围训练的模型泛化较好。

## 七、优点

1. **问题建模完整**：将通信受限MRTA形式化为Dec-POMDP，考虑了时间窗、能力、冲突、返回时间、动态拓扑等实际约束，且采用异步事件驱动决策机制，贴近真实场景。
2. **通信与规划联合建模**：策略同时输出任务决策和通信消息，使智能体能够在规划的同时主动生成对协调有用的信息，而非被动接收固定状态。
3. **扩展图注意力机制**：节点-边双向信息更新的设计捕捉了任务规划中关键的成对关系（如距离、时间窗兼容性），优于仅节点更新的架构。方向感知PE参数无额外开销。
4. **无评论家训练算法（GRMAPG）设计巧妙**：利用问题对称性构造等价实例组，以留一法组相对优势替代价值估计，既避免了评论家的额外参数，又在理论上保持梯度无偏，是解决终端奖励稀疏问题的优雅方案。
5. **实验规范**：基线适配充分（启发式适配动态拓扑、学习方法保持合理一致的模型规模），多个维度验证，且提供匿名源代码。
6. **实际部署价值**：推理时间复杂度在大规模下显著低于启发式方法，符合边缘计算场景对效率的要求。
