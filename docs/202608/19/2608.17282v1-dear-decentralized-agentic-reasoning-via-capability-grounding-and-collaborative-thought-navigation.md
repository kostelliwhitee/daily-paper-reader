## 摘要
现有的智能体推理系统通常依赖中心化协议。这种设计引入了路由瓶颈和静态角色分配，在应对复杂的多模态查询时往往失效。我们提出DeAR（去中心化智能体推理），该框架从中心控制转向自主的点对点协作。DeAR基于三种机制：（1）用于查询相关智能体专业化的去中心化能力锚定，（2）用于目标导向的同伴交互的思维图谱导航，以及（3）用于自适应错误修正的拓扑更新。在9个多样的多模态推理和基于文本的问答基准上的评估表明，DeAR持续优于最近的基线方法，验证了智能体之间的去中心化和自适应协作能增强知识密集型推理任务的准确性。源代码将在https://open_upon_acceptance上提供。

## Abstract
Existing agentic reasoning systems typically rely on centralized protocols. This design introduces routing bottlenecks and static role allocations that often fail when handling complex multimodal queries. We propose DeAR (Decentralized Agentic Reasoning), a framework that shifts from central control to autonomous peer-to-peer collaboration. DeAR is built on three mechanisms: (1) decentralized capability grounding for query-dependent agent specialization, (2) thought map navigation for targeted peer interactions, and (3) topology update for adaptive error correction. Evaluations across 9 diverse multimodal reasoning and text-based QA benchmarks indicate that DeAR consistently outperforms recent baseline methods, validating that decentralized and adaptive collaboration among agents enhances accuracy in knowledge-intensive reasoning tasks. The source code will be available at https://open_upon_acceptance.

### 一、核心问题与研究动机

- **问题背景**：现有智能体推理系统多采用**集中式协作协议**，由中央规划器（Planner）或裁判节点（Judge）统一调度和聚合来自多个专用智能体的中间结果。
- **核心缺陷**：
  - **路由瓶颈**：中心节点成为信息聚合的唯一通道，易引发单点故障和信息丢失。
  - **静态角色分配**：基于预设标签（如"数学智能体"、"视觉智能体"）的任务分配是能力的弱代理，在开放场景易导致能力幻觉（capability hallucination）与误路由。
  - **错误传播**：若某个子智能体产生幻觉或误判，中心裁判无法进行有效同伴验证，会盲目聚合错误结果，产生级联失效。
- **研究观察**：现实世界中的跨学科协作天然是**去中心化**的——专家之间不需要全能管理者逐条指示，而是通过点对点话语、协商边界、自组织来弥合知识缺口。论文认为应将这一思想引入智能体推理。

### 二、方法：DeAR 框架

DeAR（Decentralized Agentic Reasoning）的目标是用**自主点对点协作**替代中心化控制，系统被定义为四元组：

```
S = (Q, A, C, K)
```

其中 Q 为查询，A 为智能体集合，C 为协作倾向矩阵，K 为知识状态序列。框架由三阶段构成：

#### 1. 去中心化能力锚定（Decentralized Capability Grounding）

- **思想**：不预设静态角色标签，而是让每个智能体根据自身官方技术报告 / 模型卡的**可验证基准分数**锚定其能力画像。
- **能力维度**：每个智能体维护五维能力向量：
  - τᶜʳ：常识推理（由 MMLU 导出）
  - τᵉᵃ：解释能力
  - τⁿᶜ：数值计算（由 GSM8K 导出）
  - τᶠʳ：事实可靠性（由 TruthfulQA 导出）
  - τᶜᵐ：自然语言理解
- **归一化**：原始分数经 Softmax 跨所有智能体归一化到 [0,1] 区间：

  \[
  τ_i^d = \frac{\exp(s_i^d)}{\sum_{k=1}^N \exp(s_k^d)}
  \]

- **查询条件化**：收到查询 q 后，智能体动态调整能力状态：τᵢ(q) = Φᵢ(q, Pᵢ, τᵢ)，再据此生成中间知识：Kᵢ = Θᵢ(q | τᵢ(q))。

#### 2. 自组织协作与思维图谱导航（Self-Organized Collaboration & Thought Map Navigation）

- 每个智能体 aᵢ 基于当前查询维度 d，对每个其他智能体计算**协作倾向系数**：

  \[
  c_{i,j} = \frac{\exp(τ_j^d / T)}{\sum_{k≠i} \exp(τ_k^d / T)}, \quad c_{i,i}=0
  \]

  T 为温度参数控制路由锐度；自身协作被禁用。
- 所有倾向向量聚合为**协作倾向矩阵 C ∈ R^N×N**，作为思维图谱的动态邻接矩阵。
- **导航流程**：
  1. 随机选择种子智能体（或最相关的初始智能体）作为起点；
  2. 当前智能体 aᵢ 作为局部导航器，选择最大化效用 uᵢ(aⱼ) 的未访问智能体作为下一节点；
  3. 被选智能体基于累积上下文（之前所有 K 的并集）生成新知识；
  4. 重复直到**动态终止**——当所有未访问同伴的倾向值低于阈值或全部智能体耗尽时，当前智能体作为终端节点直接输出最终答案。

#### 3. 拓扑更新与渐进式精化（Topology Update with Progressive Refinement）

- 若终端智能体无法产生有效答案（"死胡同"），不丢弃整个轨迹，而是进行**局部回溯 + 边惩罚**：
  - 初始只将失效边 E_fail 设为最后一条终端边，尝试在当前深度替换路由；
  - 若局部选择耗尽，逐步向前扩展到更早的边；
  - 对失效边施加衰减因子 α（默认 0.5）：

  \[
  c_{i,j} = \begin{cases}
  \alpha \cdot c_{i,j} & (a_i \to a_j) \in E_{fail} \\
  c_{i,j} & \text{otherwise}
  \end{cases}
  \]

- 更新后的拓扑供智能体重新导航，渐进收敛到有效推理路径。

### 六、主要结论与发现

1. **去中心化优于中心化**：DeAR 在 MMMU (55.58)、MathVista (59.41)、ChartQA (89.43)、ScienceQA (62.45) 上均超越所有对比基线，证明去中心化架构能有效规避集中式瓶颈。
2. **架构增益大于参数增益**：DeAR 以四个小模型的协作，超越了 Qwen2-VL-72B（MathVista 高出 18.07 分）等大参数单模型，说明结构化协作可替代参数扩张。
3. **组件有效性**：
   - 能力锚定 + 思维图谱导航提升 MathVista 7.73 分（51.68 → 59.41），在统计推理（STA 62.9 → 80.9）、逻辑推理（LOG 19.6 → 31.0）上增益尤为显著。
   - 拓扑更新贡献平均 2-4 分的提升（MMMU 53.21 → 55.58；MathVista 55.65 → 59.41）。
4. **渐进式修正优于整体重启**：局部边惩罚 + 逐步回溯能在保留已取得进展的前提下有效导向新路径。
5. **动态激活节省资源**：MathVista 上仅 37.5% 的查询需要全部 4 个智能体激活，62.5% 查询由子集解决，验证了框架的资源自适应能力。

### 七、优点

- **问题定位准确**：明确指出集中式协议的"静态角色标签"与"中心裁判"是系统失效的结构性根源，而非模型能力不足。
- **理论形式化完整**：将协作结构编码为协作倾向矩阵 C，将推理过程建模为图谱导航，具备可解释性和可操作性；Softmax 归一化保证了数值稳定性。
- **设计巧妙**：
  - 用外部基准分数（MMLU、GSM8K、TruthfulQA）替代自评能力的幻觉来源，提升能力锚定的可信度；
  - 局部图遍历替代全局路由，保留选择性协作同时消除中心瓶颈；
  - "边惩罚 + 逐步回溯"的渐进式修正机制避免了集中式系统的全轨迹重启开销。
- **实验覆盖面好**：多模态（4）+ 文本（5）共 9 个基准，兼顾单跳与多跳问答；消融设计能够清晰分离三种机制各自的贡献。
- **效率意识强**：动态终止机制与激活频率分析表明框架在性能和计算成本之间存在自适应权衡。
