## 摘要
多智能体大型语言模型（LLM）系统常常难以与在任务中途改变策略的新队友协作。由于智能体执行多步骤或时间上扩展的技能，它们常常在公共证据表明伙伴已改变技能后很长一段时间内继续执行过时的计划。现有方法要么将伙伴跟踪视为被动上下文——使智能体意识到变化但反应迟缓——要么不加区分地重新规划。我们引入了BayesBeliefAgent，它将分层LLM规划器与贝叶斯跟踪模块相结合。我们的智能体不是不断重新规划，而是仅在伙伴的行为与推断出的技能直接矛盾时才中断当前技能。除了标准奖励之外，我们还使用重新规划效率和信念-行动差距来评估性能：即在具有正确伙伴估计的情况下，智能体执行非互补技能的总决策比例。在基准Overcooked环境中，矛盾条件控制大幅缩小了这种信念-行动差距，同时所需的重新规划次数比启发式方法少一个数量级。

## Abstract
Multi-agent Large Language Model (LLM) systems often struggle to collaborate with new teammates whose strategies shift mid-task. Because agents execute multi-step or temporally extended skills, they frequently continue executing outdated plans long after public evidence shows that a partner has changed its skill. Existing methods either treat partner tracking as passive context-leaving the agent aware of the shift but slow to act-or replan indiscriminately. We introduce BayesBeliefAgent, which pairs a hierarchical LLM planner with a Bayesian tracking module. Rather than replanning constantly, our agent interrupts its current skill only when a partner's actions directly contradict the inferred skill. Beyond standard reward, we evaluate performance using replanning efficiency and the belief-action gap: the fraction of total decisions where an agent with a correct partner estimate executes a non-complementary skill. Across benchmark Overcooked environments, contradiction-conditioned control drastically narrows this belief-action gap while requiring an order of magnitude fewer replans than heuristic methods

- 传统方法存在两类缺陷：
  - 将队友建模仅作为被动上下文（如把推断出的角色注入提示），虽能让智能体“知道”队友变化，但决策和执行仍然迟缓；
  - 或者无条件、高频率地触发重规划，造成大量计算浪费和动作抖动。
- 作者指出存在“信念-行动差距（belief–action gap）”：即使智能体对队友技能估计是准确的，它仍可能执行非互补、重复或过时的技能，导致协调失败。
- 论文的核心意义在于：不仅要“理解”队友，更要在关键时刻“打断”自身当前技能并重新规划，即实现**选择性重规划（selective replanning）**。

## 方法论

- **核心思想**：构建 BayesBeliefAgent，将分层 LLM 规划器与轻量级贝叶斯跟踪模块结合。智能体仅在队友公开动作与当前推断的队友技能**直接矛盾**时才中断自己的技能并调用 LLM 规划器。
- **技术细节**：
  1. 维护对队友活跃技能 ψjt 的后验信念 bt(ψ)，使用递归贝叶斯更新：
     - 对固定推断窗口 t′ 到 t，后验正比于似然 × 先验：bt(ψ) ∝ P(τ_{t′+1:t}|ψ) bt′(ψ)。
     - 先验使用 add-α 平滑计数模型初始化，α=1，并随观察到的技能完成情况更新（公式 4、5）。
     - 队友真实策略未知，用自身低层控制器近似动作似然：πj_low(aj|oj,ψ) ≈ πi_low(aj|τi,ψ)。
  2. 矛盾检测：
     - 在更新信念之前，计算当前 MAP 队友技能 ψ̂jt−1 下队友近期动作的似然 ℓt；若 ℓt 低于阈值 θobs 则产生矛盾信号 Ct = 1[ℓt < θobs]。
     - 该顺序很重要，避免更新后“掩盖”原先估计无法解释的新证据。
  3. 门控中断规则（公式 12）：满足以下条件才触发重规划：
     - Ct = 1（矛盾发生）；
     - MAP 估计稳定（连续 K 次更新不变）；
     - MAP 置信度 ≥ Γconf；
     - 智能体正处于技能执行中（midSkill）；
     - 尚在冷却期内（cooldown = 0）。
  4. 重规划时，LLM 规划器接收当前历史、更新后的后验、MAP 队友技能以及可行技能集合，选择新的互补技能执行。

## 主要结论与发现

- BayesBeliefAgent 在所有布局中均优于 ProAgent 和 Hypothetical Minds，在 Open/Ring 场景提升尤其显著。
- 准确的队友技能预测**不能自动**转化为有效协调：ProAgent 技能准确率几乎相同，但信念-行动差距率显著更高（Open 从 0.41 降到 0.20，Ring 从 0.38 降到 0.28）。
- 后验–门控中断比仅将后验作为提示上下文更有效：No prompt 通常优于 No replan，说明信念作为**控制信号**比作为**上下文**更重要。
- 与周期性、事件触发、LLM judge 等通用重规划启发式方法相比，矛盾条件触发在获得可比较奖励的同时，每集重规划次数极低（如 Open G1 仅 2.0 次 vs 43/169/119 次）。
- 基于 RL 的 TALENTS 和 GAMMA 仍普遍强于所有 LLM 方法，表明当前 LLM 分层规划器本身是性能瓶颈。

## 优点

- 提出“信念-行动差距”等过程级诊断指标，弥补了仅依赖聚合奖励掩盖协调失败的不足；
- 贝叶斯跟踪模块不依赖 LLM，轻量、高效，且能与 LLM 规划器无缝结合；
- 选择性重规划机制具有可解释性，只在稳定且置信度高的估计被矛盾证据推翻时触发，避免了过度重规划；
- 消融设计和重规划触发器比较严谨，能清楚分离“信念求解”与“信念用后决策”的贡献；
- 交叉配对和骨干敏感性等补充实验提升了结论的稳健性。

## 不足与局限

- 没有包含人类合作伙伴的实验，也未在更广泛的伙伴群体上验证；
