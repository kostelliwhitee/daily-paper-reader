## 摘要
视觉语言模型（VLM）擅长描述可见场景内容，但在推理动态多智能体交互方面存在困难，此类交互中的动作语义依赖于协调的角色和时空依赖关系。我们将这一能力形式化为\textbf{多智能体战术推理}，并引入\textbf{DoublesEval}，一个利用职业双打羽毛球作为结构可处理测试平台的诊断性评估框架。DoublesEval采用基于关键时刻的协议，将回合分解为战术显著时刻，并在四个可解释维度上探询模型：原子识别、段内复合理解、跨段因果推理和高级战术抽象。该设计隔离了推理\emph{在哪里}失败，而非仅仅测量答案正确性。为解决观察到的失败模式，我们提出\textbf{TacticCheck}，一种轻量级的约束引导测试时一致性检查器，利用模型自身的低级战术预测对候选答案进行重新排序，在推理时无需参数更新或真实标签。通过零样本协议，在60个精选回合（产生$\sim$9.6K个结构化实例）上评估四个具有代表性的开源VLM，我们发现模型在所有诊断层面上仍然薄弱，尤其在空间状态、交互绑定和终端证据方面存在明显瓶颈。TacticCheck在所有评估模型上均带来持续改进，但仍与稳健的战术推理存在较大差距。这些结果凸显了为下一代VLM构建结构化、面向交互的评估范式的必要性。源代码可在\href{https://github.com/Chengjt1999/DoublesEval}{\textcolor{blue}{我们的GitHub仓库}}中获取。

## Abstract
Visual Language Models (VLMs) excel at describing visible scene content but struggle to reason about dynamic multi-agent interactions, where action semantics depend on coordinated roles and spatial-temporal dependencies. We formalize this capability as \textbf{multi-agent tactical reasoning} and introduce \textbf{DoublesEval}, a diagnostic evaluation framework that leverages professional doubles badminton as a structurally tractable testbed. DoublesEval employs a key-moment-based protocol that decomposes rallies into tactically salient instants and probes models across four interpretable dimensions: atomic recognition, intra-segment composite understanding, cross-segment causal reasoning, and high-level tactical abstraction. This design isolates \emph{where} reasoning fails, rather than merely measuring answer correctness. To address observed failure modes, we propose \textbf{TacticCheck}, a lightweight constraint-guided test-time consistency checker that reranks candidate answers using the model's own lower-level tactical predictions, requiring no parameter updates or ground-truth labels at inference time. Evaluating four representative open-source VLMs on 60 curated rallies (yielding $\sim$9.6K structured instances) via a zero-shot protocol, we find that models remain weak across all diagnostic levels, with especially clear bottlenecks in spatial state, interaction binding, and terminal evidence. TacticCheck delivers consistent gains across all evaluated models, while still leaving a substantial gap to robust tactical reasoning. These results highlight the need for structured, interaction-aware evaluation paradigms for next-generation VLMs. The source code is available in \href{https://github.com/Chengjt1999/DoublesEval}{\textcolor{blue}{our GitHub repository}}.

## 2. 论文提出的方法论

### 2.1 DoublesEval 诊断框架
- 采用 **关键时刻（key-moment）协议**：将每个回合拆解为战术显著瞬间，并围绕“得分窗口”（最后得分拍及其前 3–5 拍）进行诊断。
- 定义 **四个分层诊断维度**：
  - **L1 原子识别**：单关键时刻内的基本感知（球员身份、场地分区、击球类型）。
  - **L2 段内复合理解**：将同段内多个视觉线索（空间关系、角色、动作状态）联合绑定。
  - **L3 跨段因果推理**：跨越至少两个关键时刻，建立“前一战术决策→后一动作/换位”的因果链。
  - **L4 高级战术语义抽象**：对整段比赛的战略模式（轮转、覆盖分工、攻防转换）进行归纳。
- **配对问题设计**：每个诊断维度均构造 **单选题（SCQ）** 和 **简答题（SAQ）**，共 4,800 个 SCQ + 4,800 个 SAQ。
- **专家标注**：两级标注流程——普通分析师标注全部，国家一级运动员审计 30% 子集，确保战术标签的领域有效性。

### 2.2 TacticCheck 测试时一致性检查
- **核心思想**：利用模型自身在低级维度（L1）上的预测作为“战术检查单”，对高级候选答案进行一致性重排，无需参数更新或真实标签。
- **检查单提取**：
  \[
  z = \{\hat{s}_{\text{near}}, \hat{s}_{\text{far}}, \hat{b}_{\text{near}}, \hat{b}_{\text{far}}, \hat{c}, \hat{r}\}
  \]
  包含近/远队空间状态、交互线索、结果归因和比分相关证据。
- **重排公式**：
  \[
  \text{Penalty}(o_i,z) = \lambda_s \mathbb{1}[\phi_s(o_i) \not\sim z_s] + \lambda_b \mathbb{1}[\phi_b(o_i) \not\sim z_b] + \lambda_c \mathbb{1}[\phi_c(o_i) \not\sim z_c] + \lambda_r \mathbb{1}[\phi_r(o_i) \not\sim z_r]
  \]
  \[
  \hat{o} = \arg\max_{o_i \in O} \left[\text{BaseScore}(o_i) - \text{Penalty}(o_i,z)\right]
  \]
- **优势**：轻量、无须训练、可在推理时直接介入；但受检查单本身质量限制，若 L1 预测错误，可能传播错误。

## 6. 论文的主要结论与发现

- 当前 VLM 在双打羽毛球战术推理上 **整体表现很差**：四个模型总体准确率约 27.57%–32.30%（按表 2），远未达到实用水平。
- **所有诊断维度均不饱和**：L1 原子识别虽相对最好，但仍有大量错误；L3 跨段因果推理最难（多数模型低于 L1 约 10 个百分点）。
- **瓶颈集中在空间状态、交互绑定与终端证据**：模型往往能识别局部动作或阶段，但无法将球员、球队、场地空间和结果绑定为连贯的战术状态；比分细节与击球模式（stroke pattern）是最弱的原子字段。
- **TacticCheck 带来一致提升**：SCQ 准确率提升约 7.13–8.20 个百分点（视模型而定），但仍低于 40%，且有一定比例的“对→错”翻转，说明一致性检查能缓解但无法根治问题。
- 作者强调：未来 VLM 需要更强 **交互建模能力**，仅增大视觉编码器或改进提示格式不足以解决多智能体战术推理。

## 7. 优点

- **诊断性设计**：将单一准确率拆分为四个可解释维度，能够定位模型“在哪一层、哪个能力字段”失败，而非只给一个总分。
- **领域选择合理**：双打羽毛球组合复杂度适中，既能穷尽标注又需要真正的战术理解，是研究多智能体交互的理想沙盒。
- **配对 SCQ/SAQ 设计**：同时测量“闭集判别”与“开放生成”能力，能揭示闭集与开放表达之间的“推理差距”。
- **TacticCheck 轻量且有启发性**：利用模型自身预测进行一致性约束，模仿人类教练“核对战术链条”的方式，且无需训练和标签。
- **标注质量把控**：引入国家一级运动员审计，并使用相对角色描述（如“后场发球方球员”）避免身份捷径，提高标注的领域有效性。
- **评估流程可复现**：GPT-5 标签映射裁判经人工验证，且固定解码参数，减少随机性和词法偏差。

## 8. 不足与局限

- **数据规模与多样性有限**：仅 4 场比赛、60 个回合，球员风格、战术类型和赛事场景覆盖不足，可能限制结论的泛化性。
- **未包括商业/闭源模型**：只评估了开源 VLM，结果可能不反映最先进模型的真实能力。
- **TacticCheck 依赖低级预测质量**：若 L1 检查单本身错误，重排会放大错误，导致右→左翻转；方法也没有在更广泛的任务上验证。
- **裁判主观性**：尽管 GPT-5 裁判与人类一致性较高，但在“战术抽象”维度上 κ 仅为 0.73，说明高维标签仍有歧义。
- **评估指标较单一**：主要依赖准确率，未分析置信度、推理时间、答案合理性等维度。
- **缺少参数敏感性分析**：式 (2) 中的 λ 权重没有进行消融，重排规则的保守性也未量化讨论。
- **应用边界**：实验仅针对羽毛球视频，结论是否适用于足球、篮球等更大规模多智能体场景尚未验证。
