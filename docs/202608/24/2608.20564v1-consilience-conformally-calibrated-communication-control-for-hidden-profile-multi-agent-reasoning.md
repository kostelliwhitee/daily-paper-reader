## 摘要
多智能体大语言模型系统可以通过汇集不同视角来改进推理，但其有效性取决于通信的协调，尤其是在隐配置文件设置中，每个智能体仅持有正确决策所需证据的一部分。现有协议，包括固定调度、轮流交换和非结构化辩论，无法保证对话操作的适当性。我们提出Consilience，一种推理时编排框架，在分布式私有信息下既能引导又能认证多智能体通信。在每一轮中，Consilience使用一个紧凑状态总结讨论，捕获不确定性、分歧、证据增益、冗余和过早共识，然后选择通信干预（质疑、澄清、寻求证据或路由）和合适的发言者。其核心贡献是一种逐轮共形校准程序，提供无分布、有限样本的保证：在每一讨论轮次中，以到达该轮次为条件，控制器提议动作的一步遗憾以至少1-alpha的边际概率受校准阈值约束；接受机制通过替换不可接受的提议，对已执行动作强制执行相同的保证。在跨越12个开放和封闭权重语言模型的HiddenBench风格隐配置文件任务上，Consilience相比固定和非结构化讨论协议提高了决策准确性和通信效率，有时甚至超过了每个智能体观察所有证据的全信息基线。这些结果表明，经过认证的自适应通信控制可能比增加信息可用性更有价值，为可靠的多智能体LLM协调提供了一种实用机制。

## Abstract
Multi-agent LLM systems can improve reasoning by pooling diverse perspectives, but their effectiveness depends on coordinating communication, particularly in hidden-profile settings where each agent holds only part of the evidence required for a correct decision. Existing protocols, including fixed schedules, round-robin exchange, and unstructured debate, provide no guarantee that a conversational action is appropriate. We propose Consilience, an inference-time orchestration framework that both steers and certifies multi-agent communication under distributed private information. At each turn, Consilience summarizes the discussion using a compact state capturing uncertainty, disagreement, evidence gain, redundancy, and premature consensus, then selects both a communication intervention (challenge, clarify, seek evidence, or route) and an appropriate speaker. Its central contribution is a round-wise conformal calibration procedure that provides a distribution-free, finite-sample guarantee: at each discussion round, conditional on reaching that round, the one-step regret of a controller's proposed action is bounded by a calibrated threshold with marginal probability at least 1 - alpha; an acceptance mechanism enforces the same guarantee for the executed action by replacing inadmissible proposals. On HiddenBench-style hidden-profile tasks spanning 12 open and closed weight language models, Consilience improves decision accuracy and communication efficiency over fixed and unstructured discussion protocols, sometimes surpassing a full-information baseline where every agent observes all evidence. These results demonstrate that certified adaptive communication control can be more valuable than increasing information availability, providing a practical mechanism for reliable multi-agent LLM coordination.

## 论文中文总结：Consilience

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：大型语言模型（LLM）越来越多地被部署为多智能体系统，通过多个智能体交换论点、互相批评来共同决策。但研究表明，单纯增加讨论轮次或智能体数量并不能保证更好的集体推理，因为多智能体讨论可能复制单个智能体的能力、放大相关错误，或过早收敛于有说服力但错误的结论。
- **核心挑战（隐藏配置文件）**：论文聚焦于 **隐配置文件（hidden-profile）** 范式——即任务相关信息分布在多个智能体之间，每个智能体只拥有部分证据，没有个体能单独做出正确决策。该范式源于社会心理学（Stasser & Titus, 1985），其典型失败模式是 **共同信息偏差（common-information bias）**：共享信息更容易被提及和强化，而每个智能体独有的关键证据得不到充分挖掘。
- **现有方法的不足**：固定调度、轮询（round-robin）和无结构辩论等协议无法适应不断演化的讨论状态，无法保证某次对话动作（如选择哪个说话者、何时终止）是合适的；而无约束的 LLM 编排器可能做出不可靠的控制决策，且**不提供任何统计保证**。
- **核心主张**：通信控制应被视为一个**顺序决策问题**，而非固定提示协议。认证过的自适应通信控制（certified adaptive communication control）可能比单纯增加信息可用性更有价值。

### 2. 方法论：核心思想、关键技术细节、算法流程

**核心思想**：Consilience 是一个推理时（inference-time）闭环编排框架，通过"状态构建 → 动作提议 → 共形认证 → 路由执行"的循环，同时**引导并认证**多智能体的通信。

**技术细节**：框架由五个阶段组成（详见下图框架流程）：

- **Stage 1：信念诱导与状态构建**
  - 每个智能体在公共转录本条件下报告其对各候选答案的概率分布 \(p_i^{(t)}\)；汇总为算术平均聚合信念 \(\bar{p}^{(t)}\)。
  - 构建六维集体状态 \(s_t\)：
    - **组不确定性 \(H_t\)**：聚合信念的归一化熵；
    - **智能体间分歧 \(D_t\)**：各智能体信念与聚合信念的 Jensen–Shannon 散度均值；
    - **消息冗余 \(R_t\)**：基于词法重叠与 LLM 评估的消息重复程度；
    - **证据增益 \(G_t\)**：消息是否贡献了决策相关的新事实；
    - **通信成本 \(C_t\)**：转录本归一化词数；
    - **过早共识 \(P_t\)**：高置信但近期证据薄弱时的风险信号。
  - 由此定义代理讨论损失 \(J(s_t) = \alpha_H H_t + \alpha_D D_t + \alpha_R R_t - \alpha_G G_t + \alpha_C C_t + \alpha_P P_t\)。

- **Stage 2：通信动作提议**
  - 动作空间包含四个非终止干预：**Challenge（质疑）**、**Clarify（澄清）**、**SeekEvidence（寻求证据）**、**Route（路由）**；可选 **Vote（投票/终止）**。
  - 提供三种控制器变体：**规则型**（固定阈值）、**学习型 MLP**（训练一个 6→12→4 的轻量 MLP 预测各动作反事实奖励）、**LLM 型**（让 LLM 依据转录本与状态选择动作）。

- **Stage 3：反事实评估与共形接受**
  - 对每个可行动作，从相同的冻结前置状态独立执行一次反事实分支，得到候选下一状态 \(s_{t+1}^a\)，计算**一步改进** \(r_t(s_t, a) = J(s_t) - J(s_{t+1}^a)\)。
  - 定义**一步遗憾**（non-conformity score）为 \(\mathcal{R}_t(s_t, a) = \max_{a'} r_t(s_t,a') - r_t(s_t,a)\)。
  - **离线逐轮共形校准**：对每个轮次 \(t\)，用校准轨迹中到达该轮的分数集合构造阈值 \(\epsilon_t\)（第 \(k_t\) 小的分数，\(k_t = \lceil(n_t+1)(1-\alpha)\rceil\)）。
  - **在线接受机制**：若提议动作的遗憾在阈值内则直接通过；否则从共形可接受集合 \(\Gamma_t(s) = \{a : \mathcal{R}_t(s,a) \le \epsilon_t\}\) 中选择最小遗憾成员作为替代。
  - 该机制提供 **Proposition 1 的逐轮边际保证**：\(P(\mathcal{R}_t(s_{\text{test}}, \pi_m(s_{\text{test}})) \le \epsilon_t \mid \text{到达轮次 }t, N_t=n_t) \ge 1-\alpha\)，即控制器提议的一步遗憾以至少 \(1-\alpha\) 的概率被校准阈值约束（分布无关、有限样本）。

- **Stage 4：动作条件路由与转录本更新**
  - 对分歧类动作（Challenge、Clarify），选择与聚合信念 JSD 差异最大的智能体；
  - 对证据获取类动作（SeekEvidence、Route），选择发言次数最少的智能体；
  - 被选智能体按动作特定提示生成一条消息，更新公共转录本，进入下一轮。

- **Stage 5：终止与集体预测**
  - 当 Vote 被选中、达到早停条件或最大轮数 \(T\) 时终止；
  - 各智能体独立投票并给出置信度，最终采用**多数投票 + 置信度加权平局打破**得到集体答案。

### 3. 实验设计

- **数据集与基准**：
  - **HiddenBench**（Li, Naito, Shirado, 2025）：65 个隐配置文件决策任务，涵盖自定义场景、前人人类研究和自动生成的决策问题；
  - **生成基准**：按照 GroupTravelBench（Cheng et al., 2026）任务结构独立生成的旅行计划基准（因原始数据不可得，非直接复现）。
- **评估模型**：12 个指令微调开放权重模型（Qwen3 系列 0.6B–32B、Qwen2.5-32B、Llama-3.1-8B、Phi-4、Mistral-24B、DeepSeek-V4-Flash/Pro）；附录中另有补充实验涵盖 13 个开放权重模型及 GPT-4.1-mini、Claude-3-Haiku 两个闭源 API 模型。
- **对比方法**：
  - **Hidden-Pre**：无讨论直接投票（最低信息基线）；
  - **Hidden-Post**：固定轮询讨论后投票；
  - **Full-Info**：所有智能体直接获得全部证据但不讨论（信息丰富基准）；
  - **Consilience 四种控制器**：Rules（规则型）、MLP（学习型）、LLM（LLM 控制器）、LLM+Vote（自适应投票）。
- **评估指标**：**任务准确率**（集体最终答案正确率，主指标）和**投票准确率**（个体投票一致正确率，辅助指标）。

### 6. 主要结论与发现

- **RQ1（自适应通信是否有效）**：Consilience 在所有受控协议中持续优于无讨论和固定轮询基线。最强控制器平均任务准确率达 **0.83**，相比固定轮询的 0.26 实现 **0.57 的绝对提升**。
- **RQ2（分布式讨论能否匹敌全信息）**：最佳 Consilience 策略在 12 个模型中的 **11 个上达到或超过全信息基线**，平均高出 **0.13**，说明结构化通信能够比单次呈现全部事实更有效地整合证据。
- **RQ3（控制器设计的影响）**：规则型控制器平均表现最佳（0.83），LLM 与 LLM+Vote 次之（0.80），MLP 为 0.77。LLM 型控制器在不同模型规模上行为不同：自适应投票有利于小模型（避免上下文漂移），大模型则受益于更长的讨论。
- **RQ4（泛化能力）**：仅在 5 个任务上训练的 held-out MLP 平均准确率达 0.73（全任务 MLP 为 0.77），表明六维状态表示捕捉的是可复用的协调条件而非任务特定内容。
- **总体判断**：经过认证的自适应通信控制可以比增加信息可用性更有价值，为可靠的多智能体 LLM 协调提供了实用机制。

### 7. 优点

- **理论保证**：将共形预测框架引入多智能体通信控制，提供分布无关、有限样本的逐轮边际后悔保证，是不确定性量化方法在 LLM 智能体编排中的创新应用。
- **反事实分支设计**：所有候选动作从同一冻结前置状态独立评估，只有最终接受的分支才提交到实际转录本，实现"安全试错"。
- **控制器与路由器解耦**：动作提议与说话者选择分离，支持各种控制器（规则/MLP/LLM）与不同路由策略的灵活组合。
- **紧凑状态表示**：六维状态（不确定性、分歧、冗余、证据增益、成本、过早共识）既支撑可解释的规则控制器，也便于轻量级学习器的跨任务泛化。
- **广泛评估**：覆盖开放/封闭权重模型、同构/异构智能体、多个基准与丰富消融，实验设计较为系统和全面。

### 8. 不足与局限

- **理论保证的范围限制**：Proposition 1 的保证是**逐轮边际**的，不提供整条轨迹的联合覆盖；且顺序设置下后续轮次的交换性需要额外假设（附录中明确说明）。执行动作的确定性保证依赖"接受后不重采样"这一前提。
- **评测基准局限**：生成的 GroupTravelBench 基准不是原始数据的复现，结果不能与之直接可比；全信息基线是经验参照，不能视为理论上界。
- **MLP 泛化实验的混淆**：附录承认全任务 MLP（65 任务）与 held-out MLP（60 任务）的对比混入了任务集差异，严格估计需要两者在同一 60 任务子集上对比。
- **未报告算力成本**：缺少 GPU 型号、数量、训练时长等具体资源信息，难以评估实际部署成本。
- **数据集性能差异**：在生成的旅行规划基准上，所有控制器的表现整体低于 HiddenBench（LLM+Vote 下降最小 0.115，MLP 下降最大 0.261），显示控制器鲁棒性存在任务分布依赖。
- **语义捕捉能力有限**：冗余度、证据增益等信号依赖固定 LLM 评估器，可能无法完全捕捉复杂语义关系；JSD 等统计量对信念分布的刻画也较为粗糙。
