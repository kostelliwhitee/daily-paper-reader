## 摘要
在无集中式路由控制的分布式智能体互联网（IoA）中，将任务路由到能力匹配的执行者具有挑战性，因为目的地并非预先确定，且智能体仅具有有界的局部服务视图。相比之下，先发现后转发的方法在网络转发前选择执行者，因此当下游出现额外候选者时，无法直接支持重新选择。我们提出语义势场路由（SPFR），一种分布式IoA路由算法，将执行者发现与重新选择集成到逐跳转发中。SPFR将局部语义转发信息库（FIB）中可见的每个执行者表示为任务条件化的语义势源，其效用设定强度，跳数距离引起指数衰减。在每一跳，转发智能体重计算这些势，重新选择主导执行者，并将任务向其转发一跳。在任务一致的冻结FIB条件下，我们证明了无环性和有限跳终止，并在有界可见性下相对于全可见性目标推导出显式加性误差界。在真实拓扑上的大量仿真表明，SPFR在实现分布式效用贪心路由与请求触发全局发现的已实现效用方面接近，同时使用更少的转发跳数和显著更少的请求触发消息，并且在网络和服务动态下保持鲁棒性。

## Abstract
In a distributed Internet of Agents (IoA) without centralized routing control, routing tasks to capability-matched executors is challenging because destinations are not predetermined and agents have bounded local service views. Discover-then-forward approaches, by contrast, select an executor before network forwarding and therefore do not directly support reselection when additional candidates become visible downstream. We introduce Semantic Potential Field Routing (SPFR), a distributed IoA routing algorithm that integrates executor discovery and reselection into hop-by-hop forwarding. SPFR represents each executor visible in a local semantic forwarding information base (FIB) as a task-conditioned semantic potential source, with utility setting its strength and hop distance inducing exponential attenuation. At each hop, the forwarding agent recomputes these potentials, reselects the dominant executor, and forwards the task one hop toward it. Under task-consistent frozen-FIB conditions, we prove loop freedom and finite-hop termination and derive an explicit additive error bound under bounded visibility relative to the full-visibility objective. Extensive simulations on real-world topologies show that SPFR approaches the realized utility of distributed utility-greedy routing and request-triggered global discovery while using fewer forwarding hops and substantially fewer request-triggered messages, and remains robust under network and service dynamics.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：分布式智能体互联网（Internet of Agents, IoA）将异构自主智能体互连，用于协作任务执行。智能体跨边缘和云基础设施、多管理域，暴露模型、工具和服务供远程调用。这样的环境要求能力感知的服务发现以及请求转发、结果交付的网络支持。
- **核心问题**：
  - 分布式 IoA 没有集中式路由控制，任务指定所需能力而非固定执行者地址，因此路由需要同时解决"选择合适执行者"和"将任务交付给它"两个问题。
  - 保持每个智能体了解所有执行者的能力和动态服务状态需要频繁的全局网络级扩散，代价高昂；当这种扩散受限时，每个智能体只能观察到位置相关的候选集合。
  - 现有的"先发现后转发"（discover-then-forward）方法在网络转发前选定执行者，因此当下游转发节点能看到上游不可见的、更优的新候选执行者时，无法进行重新选择。
- **论文定位**：既有的智能体侧协议（A2A、ANP、AgentDNS、BiRouter、AMRO-S、AIN）和网络侧方案（QoS/多准则路由、势场路由）均未提供在逐跳转发过程中联合更新任务相关执行者选择和下一跳转发的分布式 IoA 路由算法。SPFR 填补了这一空白。

## 2. 论文提出的方法论

**核心思想**：将执行者发现与重选集成到逐跳转发中，利用语义势场引导路由。

- **系统模型**：网络建模为有限连通无向图 G=(V,E)。服务能力智能体发布描述符，语义控制平面在有界跳数半径内进行扩散，形成每个智能体的本地语义转发信息库（semantic FIB）。
- **关键概念**：
  - **执行者效用**：UT(j) = ws·S(j,T) + wl·(1−ρTj) + wp·(1−eπj(T))，综合考虑语义匹配度、归一化投影负载和归一化执行价格。
  - **语义势**：ϕi(j,T) = UT(j)·exp[−ωh·hi(j)]，效用决定势源强度，跳数距离引起指数衰减。ωh 为跳衰减系数，控制效用与局部性之间的权衡。
  - **候选继承（Candidate Inheritance）**：如果当前节点 i 将任务转发给执行者 j 的下一跳 k，则 j 在 k 的 FIB 中仍然可见且剩余跳数减一，即下游节点继承上游候选者。
- **逐跳转发过程（Algorithm 1）**：
  1. 源节点基于本地 FIB 计算所有可见执行者的势 ϕi(j,T)；
  2. 选择势最大的主导执行者；
  3. 若主导执行者就是当前节点，则执行任务并回复；
  4. 否则，将任务转发到 FIB 中指向该执行者对应的下一跳；
  5. 下一跳节点重复此过程，由于局部视图不同，可能发现并改选更强的执行者。
- **理论分析**：
  - 将联合执行者–路径选择问题形式化为 P1，证明其 NP-hard（通过 PARTITION 归约）；
  - 引入仅效用的上界基准 P1′ 和跳数正则化全局目标 P2；
  - 证明在"任务一致冻结快照"条件下，候选继承带来严格主导势上升（Φ 至少乘以 exp(ωh)），从而证明无环和有限跳终止；
  - 全可见性下证明 SPFR 精确实现 P2 最优；有界可见性下推导显式加性误差界 P2Gap_T ≤ Umax·exp[−ωh(Hctrl+1)]。

- **对比方法**：

- **主实验结果**：

  - SPFR 保留 GLOBAL† 效用的 97.63%，但请求触发消息减少 81.24×。
  - 三种拓扑上结果一致，说明结论具备跨拓扑泛化性。
- **机制归因实验**：在源视图已充分的本地任务上，SPFR 与 SRC-FIX 效用几乎相同（0.831 vs 0.832），证明重选无人工增益；在需移动视图任务上，SPFR 效用提升 18.19%，证明局部移动视图的实际价值。
- **消融实验**：去除重选降低效用 1.10%；去除跳衰减虽提高效用 1.69%，但跳数和消息量分别增加 56.0% 和 39.2%；移除语义相似度项造成最大效用损失（6.13%）。
