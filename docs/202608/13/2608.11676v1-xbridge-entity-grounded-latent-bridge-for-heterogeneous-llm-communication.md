## 摘要
异构多智能体大语言模型系统中，由不同模型家族驱动的智能体可以通过减少冗余推理模式而优于同构配置。然而，现有通信协议要么通过文本操作，丢弃发送方的内部表示，要么要求架构同构以实现潜在层传递。我们识别了跨架构通信中的实体锚定问题：跨注意力桥梁在不同LLM家族之间传递连续表示时，会遭受稀有标记压缩崩溃，导致实体身份在连续瓶颈中丢失（仅桥梁F1约30%）。我们提出XBRIDGE，一种无需解码的通信协议，通过两种机制解决此问题。词汇锚定映射（LAM）将发送方的原始上下文标记映射到接收方的词汇表，提供离散实体锚点。潜在增强桥梁（LEB）允许接收方查询发送方的隐藏状态以进行上下文增强。实体锚点通过接收方自身的自注意力将桥梁的上下文信号锚定到特定实体。跨越三个模型家族（Llama、Qwen和Mistral）、七个基准测试以及两个通信方向，XBRIDGE在每对模型的全部七项任务上优于基于文本的通信，同时实现11倍更低的延迟，并且在同架构设置中，它在七项任务中的六项上也超过了KV共享基线。LEB仅需264M可训练参数（占接收方的3.8%），在小规模平衡样本集上训练，并增加了可忽略的推理开销。

## Abstract
Heterogeneous multi-agent LLM systems, where agents are powered by different model families, can outperform homogeneous configurations by reducing redundant reasoning patterns. Yet existing communication protocols either operate through text, discarding the sender's internal representations, or require architectural homogeneity for latent-level transfer. We identify the entity grounding problem in cross-architecture communication: cross-attention bridges that transfer continuous representations across different LLM families suffer from rare-token compression collapse, where entity identity is lost in the continuous bottleneck (bridge-only F1 ~30%). We propose XBRIDGE, a decode-free communication protocol that addresses this through two mechanisms. Lexical Anchor Mapping (LAM) maps the sender's original context tokens to the receiver's vocabulary, providing discrete entity anchors. A Latent Enrichment Bridge (LEB) lets the receiver query the sender's hidden states for contextual enrichment. The entity anchors ground the bridge's contextual signals to specific entities through the receiver's own self-attention. Across three model families (Llama, Qwen, and Mistral), seven benchmarks, and both communication directions, XBRIDGE outperforms text-based communication on all seven tasks for each model pair while achieving 11x lower latency, and in a same-architecture setting it also exceeds a KV-sharing baseline on six of seven tasks. LEB requires only 264M trainable parameters (3.8% of the receiver), is trained on a small balanced sample set, and adds negligible inference overhead.

# XBridge: 实体锚定的异构大语言模型通信潜在桥梁 —— 论文总结

## 1. 核心问题与研究动机

- **背景**：多智能体大语言模型（Multi-agent LLM）系统可通过多次推理分发提升推理能力，但同构智能体（相同参数与归纳偏置）容易退化为冗余的“多数投票”式交互，难以带来互补性的推理。  
  异构模型（不同模型家族、分词器、训练语料、架构与对齐方式）组成的组合能缓解这一冗余，但引入严重的通信瓶颈——不同模型的潜在空间结构不兼容，信息难以高效传递。
- **现有范式的问题**：
  - **文本通信（NLComm）**：架构无关，但需要自回归解码，延迟高，且将发送方内部状态压缩为文本摘要，丢失大量上下文与关系结构信息。
  - **潜在层通信（如 KV 共享、隐藏状态注入）**：通常要求架构同构，如隐藏维度、注意力布局、位置编码甚至分词器一致，限制了异构场景的适用性。
  - **连续投影跨架构传输**：尽管能传递上下文信息，但在实践中出现“**实体锚定问题（Entity Grounding Problem）**”：连续桥接虽然保留了上下文语义，却无法准确保留离散的实体身份（如人名、数字、稀有标记），即“**稀有标记压缩坍塌（Rare-token Compression Collapse）**”。仅靠连续桥接时 F1 仅约 30%。
- **核心目标**：实现一种**无解码（decode-free）**、跨架构、既保留发送方内部表示又保持实体保真度的异构 LLM 通信协议。

## 2. 方法论：XBRIDGE

### 2.1 总体框架
- XBRIDGE 采用**非对称通信**设定：发送方 \(M_S\) 仅观察上下文 \(C\)，接收方 \(M_R\) 仅观察问题 \(Q\) 并生成答案 \(A\)。
- 发送方通过一次前向传播产生：
  - 上下文 token 序列 \(c_S = \tau_S(C)\);
  - 最后一层隐藏状态 \(H_S \in \mathbb{R}^{T_C \times d_S}\)。
- XBRIDGE 同时传输两个信号：
  - **离散通道**：LAM 提供实体锚点；
  - **连续通道**：LEB 提供上下文增强。

### 2.2 词汇锚定映射（LAM，Lexical Anchor Mapping）
- **跨词表映射** \(\phi: V_S \to V_R^*\)：
  - 若发送方 token 的字符串出现在接收方词表中，直接做 ID 到 ID 的查找；
  - 否则退化为字符串回退（string fallback）：解码该 token 为表面字符串，再使用接收方分词器重新切分，产生一个或多个接收方 token。
  - 该映射是**确定性、无需训练、无损**的，且离线预计算一次，推理时额外延迟不到 1 ms。
- **接收方原生词嵌入**：将映射后的 ID 用接收方冻结嵌入矩阵 \(E_R\) 查表，获得 \(e_{ctx}\)，拼接到问题嵌入之前：
  \[
  x_R = [e_{ctx}; E_R(Q)]
  \]
- 相比需要自回归解码的文本摘要，LAM 将完整上下文以接收方原生词空间直接输入，无解码、无固定长度压缩损失。

### 2.3 潜在增强桥（LEB，Latent Enrichment Bridge）
- 在接收方 28 层中选取第 6、13、20、27 层插入共 4 个**门控交叉注意力模块**（每模块约 66M 参数，总数 264M，约为接收方的 3.8%）。
- **投影**（处理维度不匹配 \(d_S \to d_R\)）：
  \[
  Q^{(\ell)} = W_Q^{(\ell)} \cdot LN_R^{(\ell)}(h_R^{(\ell)}), \quad
  K^{(\ell)} = W_K^{(\ell)} \cdot LN_S^{(\ell)}(H_S), \quad
  V^{(\ell)} = W_V^{(\ell)} \cdot LN_S^{(\ell)}(H_S)
  \]
- **交叉注意力**：接收方当前隐藏状态作为查询，发送方最后一层隐藏状态作为键值，通过缩放点积注意力提取相关信息：
  \[
  A^{(\ell)} = \text{softmax}\left(\frac{Q^{(\ell)} K^{(\ell)\top}}{\sqrt{d_k}}\right) V^{(\ell)}
  \]
- **门控残差连接**（避免向接收方注入分布外激活）：
  \[
  h_R'^{(\ell)} = h_R^{(\ell)} + \tanh(\alpha^{(\ell)}) \cdot A^{(\ell)}
  \]
  初始化 \(\alpha=1.0\)（相比 Flamingo 的零初始化收敛更快），使桥接信号一开始即生效。
- **训练**：仅训练桥接模块，发送方与接收方全部冻结；损失为答案 token 的标准下一词预测（NTP）：
  \[
  \mathcal{L}(\theta) = -\sum_{t=1}^{|A|} \log P_R(a_t | a_{<t}, e_{ctx}, Q; \theta_{bridge})
  \]
- 发送方输出可预计算缓存，训练仅需**单卡 10 分钟内**完成，使用 587 条跨任务平衡样本；推理时桥接开销可忽略。

### 2.4 实体锚定与桥接的整合
- LAM 将实体（如 “Christopher Nolan”）放在接收方输入中，经过自注意力传播后，接收方各层隐藏状态 \(h_R^{(\ell)}\) 中已编码“哪些实体存在、出现在哪”。LEB 以该隐藏状态为查询，就能从发送方 \(H_S\) 中检索与这些实体相关的上下文信息。
- 实体锚定是 LEB 发挥作用的“使能条件”：
  - 无 LAM：LEB 孤立性能仅提升 +5.7 pp（NoComm 24.6 → 30.3 F1），实体身份在连续瓶颈中丢失；
  - 有 LAM + LEB：提升 +54.2 pp，达到 78.8 F1。
- 实体扰动实验表明角色分离明确：**LAM 决定“哪些实体”出现在答案中，LEB 决定“如何推理”这些实体**。
