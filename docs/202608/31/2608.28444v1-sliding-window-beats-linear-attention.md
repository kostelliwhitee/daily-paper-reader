## 摘要
由于二次注意力的本质，大型语言模型（LLM）消耗大量内存和能源。每个新词元都比前一个花费更多。每增加一个词元，键和值就必须无限期地存储在内存中，这是不可持续的。已有多种替代方案被提出来解决二次缩放问题，其中之一是将LLM改造为使用线性注意力。鉴于其承诺以低代价解决二次缩放问题并达到最先进的性能，这一想法引起了广泛关注。然而，这一研究方向尚未与更简单的基线进行适当比较。在本工作中，我们表明带汇聚（sink）的滑动窗口注意力（SWA）在性能上与后训练的线性注意力模型相当或更好。我们在多种下游任务上的多个LLM中观察到这一点。对于长上下文推理任务（大海捞针和BABILong），SWA实现了大幅更高的性能（比线性注意力高2到10倍）。SWA无需后训练，速度极快，且内存需求低；因此，它是一种极其廉价且可靠的解决方案。为了降低推理内存成本，我们强烈建议改用SWA，而非后训练线性模型。线性注意力模型可能显示出一些潜力，但为了甚至达到与SWA相当的水平，它们可能需要从头训练或进行大量后训练。

## Abstract
Due to the nature of quadratic attention, Large Language Models (LLMs) consume a lot of memory and energy. Every new token costs more than the previous one. For each additional token, the keys and values must be stored in memory indefinitely, which is unsustainable.   Several alternatives have been proposed to fix the quadratic scaling problem, one of which is retrofitting LLMs to use Linear Attention. This idea has attracted a lot of attention, given its promise to solve the quadratic scaling problem with state-of-the-art performance at low cost. However, this line of research has not been properly compared to simpler baselines.   In this work, we show that Sliding Window Attention (SWA) with sinks performs as well or better than post-trained Linear Attention models. We observe this across multiple LLMs on various downstream tasks. For long-context reasoning tasks (Needle-in-a-Haystack and BABILong), SWA achieves massively higher performance (2 to 10 times higher than linear attention). SWA requires no post-training, is extremely fast, and requires low memory; therefore, making it an extremely cheap and reliable solution.   To reduce inference memory cost, we strongly recommend switching to SWA instead of post-training linear models. Linear attention models may have shown some promise, but they likely require to be trained from scratch or extensive post-training in order to even match SWA.

## 论文详细总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心背景**：大型语言模型（LLM）基于二次复杂度的 Softmax 注意力机制，导致推理时的 KV 缓存随上下文长度线性增长，内存和计算成本难以承受。每新增一个 token，Keys 和 Values 都必须被持久化存储，成本不断上升，这种模式不可持续。
- **主要动机**：线性注意力（Linear Attention）被视为解决二次缩放问题的有前途的方案，通过将 Softmax 注意力转化为线性循环形式，使推理成本变为常数级、内存占用固定。近年来，许多工作（如 MOHAWK、LoLCATs、Liger-GLA、QRWKV6 等）声称通过后训练可以将预训练 Transformer 转化为线性注意力模型，并恢复大部分性能。
- **研究的核心问题**：这些后训练线性注意力工作在与基线对比时，通常只与"无 sink"的滑动窗口注意力（SWA）比较，而 SWA 在缺少注意力汇聚（attention sink）时会性能崩溃。因此，线性注意力是否真的优于**带 sink 的 SWA** 这一更简单、无需训练的基线，尚未得到公平检验。本文正是为了填补这一空白。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：本文并非提出新的注意力机制，而是进行系统性对比研究。核心主张是：**带注意力汇聚（sinks）的滑动窗口注意力（SWA）是一个极强的、无需任何后训练的基线**，其性能足以媲美甚至超越需要大量微调的后训练线性注意力模型。
- **SWA 的定义与表示**：使用 SWA(w, s) 表示滑动窗口注意力，其中 w 为窗口大小（实验中从 64 到 512 不等），s 为注意力汇聚（sink）的数量（论文固定为 4）。在每一步，模型不仅仅关注前 w 个 token，还额外关注序列最开头的 4 个 token（sink tokens）。这种做法解决了 SWA 在窗口滑动越过初始 token 后的灾难性性能退化问题。
- **与线性注意力的区别**：
  - 线性注意力通过核函数 φ 将 Softmax 近似为 φ(qt)φ(ki)⊤，从而将复杂度 O(L²) 降至 O(L)，推理时只需维护常数大小的循环状态。
  - SWA(64, 4) 则不加任何改造，直接复用预训练模型原有的权重，仅修改注意力掩码（mask），使每个位置仅关注前 w 个 token 与最初的 4 个 sink tokens。
- **无需训练的前提**：SWA 直接复用预训练模型（如 Llama-3.1-8B）的权重，无需任何微调或适配，属于"开箱即用"（training-free）的推理期改造方案。
- **公式/算法流程**：对于第 t 个 token，SWA 的注意力计算可表示为对 i ∈ [max(1, t−w+1), t] ∪ [1, 4]（前 4 个 token）范围内的键值进行 Softmax 加权求和；窗口之外的历史 token 被完全忽略，从而将注意力 FLOPs 和内存开销从 O(L²) 降为 O(L·w)。
