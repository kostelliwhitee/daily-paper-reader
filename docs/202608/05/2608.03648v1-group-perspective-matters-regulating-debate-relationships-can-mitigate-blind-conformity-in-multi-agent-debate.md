## 摘要
多智能体辩论（MAD）通过多轮交互提升了大语言模型（LLMs）的推理性能。然而，MAD中的LLMs极易产生盲从行为。现有的个体评估方法通常基于置信度或困惑度，难以反映推理的正确性，甚至可能加剧盲从。为解决这一问题，我们将视角从个体评估转向群体互动。我们将LLMs之间的相互参照定义为	extbf{辩论关系}，并认识到调节这些关系是缓解盲从的关键。在本文中，我们提出了一种从群体视角出发的	extbf{动态调节辩论关系}（DEAR）新框架。首先，DEAR将共识与分歧量化为	extit{群体证据}，以捕捉辩论状态。然后，DEAR通过三个阶段运作：1）是什么：感知群体协商倾向与不确定性；2）谁：引入一个选择RL智能体来动态选择参考同伴；3）如何：采用行为RL智能体自适应调整生成行为。值得注意的是，我们将两个RL智能体的执行过程构建为序贯决策过程，通过多智能体强化学习联合优化。大量实验表明，DEAR在显著降低令牌消耗的同时实现了优越的性能。

## Abstract
Multi-Agent Debate (MAD) improves the reasoning performance of Large Language Models (LLMs) through multi-round interaction. However, LLMs in MAD are highly susceptible to blind conformity. Existing individual evaluation methods, typically based on confidence or perplexity, fail to reflect the correctness of reasoning and may even exacerbate blind conformity. To address this, we shift the perspective from individual evaluation to group interaction. We define mutual referencing among LLMs as \textbf{Debate Relationships} and recognize that regulating these relationships is the key to mitigating blind conformity. In this paper, we propose a novel framework for \textbf{D}ynamically r\textbf{E}gulating deb\textbf{A}te \textbf{R}elationships (DEAR) from the group perspective. At first, DEAR quantifies consensus and divergence as \textit{group evidence} to capture the debate state. Then, DEAR operates through three stages: 1) What: perceiving group consultation tendency and uncertainty; 2) Who: introducing a Selection RL-Agent to dynamically select reference peers; and 3) How: adopting a Behavior RL-Agent to adaptively adjust generation behaviors. Notably, we formulate the execution of the two RL-Agents as a sequential decision-making process, jointly optimizing via multi-agent reinforcement learning. Extensive experiments demonstrate that DEAR achieves superior performance while significantly reducing token consumption.

## 1. 论文的核心问题与整体含义（研究动机与背景）

多智能体辩论（Multi-Agent Debate, MAD）通过组织多个大语言模型（LLMs）围绕同一问题开展多轮交互，能够有效提升推理能力并缓解幻觉。然而，MAD 中 LLMs 极易出现**盲从现象**——少数派模型往往放弃自身独立推理而倒向多数派意见，导致错误共识被放大。

论文指出现有缓解盲从的方法存在根本缺陷：

- **基于置信度的方法**：LLMs 普遍存在"过度自信"问题，常对错误推理赋予高置信度，且置信度校准无法根治；
- **基于困惑度的方法**：困惑度衡量的是文本流畅性而非推理正确性，低困惑度的输出仍可能是错误答案；
- 更关键的是，上述方法采用**固定阈值**做个体层面的筛选，无法捕捉辩论过程中动态演化的群体互动状态，甚至可能加剧盲从。

因此，论文提出将视角从**个体评估**转向**群体互动**，将 LLMs 之间的相互参照定义为**辩论关系**（Debate Relationships），认为调节辩论关系才是缓解盲从的关键。核心洞察是：盲从本质上是多数派主导下的**群体现象**，需要从群体层面进行治理。

## 2. 论文提出的方法论：DEAR

论文提出 **DEAR（Dynamically rEgulating debAte Relationships）** 框架，核心思路是从群体视角动态调节辩论关系，全程不微调 LLMs 的任何内部参数。

### 2.1 整体框架

整个调节过程被建模为**部分可观测马尔可夫决策过程（POMDP）**，包含两个异构 RL 智能体：
- **Selection RL-Agent**（策略 ρ）：负责选择每个 LLM 应参考哪些同伴的回复；
- **Behavior RL-Agent**（策略 π）：负责调节每个 LLM 的生成行为（温度 temperature 和核采样 top-p）。

二者的联合策略满足概率链式法则：

\[
\pi_{all}(id_s, a \mid s) = \rho(id_s \mid o_\rho) \cdot \pi(a \mid o_\pi)
\]

### 2.2 群体证据提取

DEAR 从配对 LLM 回复中提取两类相似度作为群体证据：
- **结论相似度**：利用预训练文本编码器 BGE-M3 将结论映射到潜空间，计算缩放余弦相似度；
- **推理相似度**：对推理过程做同样的相似度计算。

将所有配对得分聚合为群体证据矩阵 \(\mathbf{E}^{agent}\)。该矩阵基于模型间语义相似度而非任务特定语义，因此具有**任务无关性**。

### 2.3 What：群体证据解耦

借助**主观逻辑（Subjective Logic, SL）**，将群体证据解耦为：
- **协商倾向** \(b_{ij}\)（belief mass，LLM i 对同伴 j 的信任程度）；
- **不确定性** \(u_i\)（LLM 对同伴可信度的整体不确定性）。

满足约束：\(u_i + \sum_{j \in V} b_{ij} = 1\)。

### 2.4 Who：自适应辩论者选择

Selection RL-Agent 将协商倾向、不确定性和 one-hot 身份嵌入拼接为群体观测 \(o_\rho\)，通过映射网络输出偏好矩阵，将同伴选择建模为**独立伯努利变量的联合采样**，决定每个 LLM 下一轮参考哪些同伴。这相当于为每轮辩论动态构建交互掩码，选择性切断有害回复的传播路径。

### 2.5 How：生成行为调整

- 利用 **Dempster-Shafer 证据理论（DST）**的组合规则，融合 LLM 自身信念与被选同伴的信念，显式量化共识与分歧；
- 基于融合后的证据 \(\hat{E}_i\)，通过 Behavior RL-Agent 的高斯策略采样连续变量，经 Sigmoid 映射到合法范围内的温度与 top-p 值；
- 从而自适应调节每个 LLM 的生成行为，在探索与收敛之间取得平衡。

### 2.6 优化方案

两个 RL 智能体的执行构成**序贯决策过程**，论文采用 **HAPPO（异构智能体近端策略优化）** 算法进行端到端联合训练，保证联合策略的单调改进。Selection RL-Agent 先优化，Behavior RL-Agent 的替代优势通过 Selection 的重要性采样比率进行条件化缩放，全局 Critic 负责优势估计。

## 6. 论文的主要结论与发现

1. **DEAR 显著提升推理性能**：在数学与 QA 任务的平均准确率上均大幅超越现有 MAD 方法。例如 GPT-4o-mini 上，数学平均准确率 65.1%（次优为 59.7%），QA 平均准确率 75.0%（次优为 70.3%）。

2. **DEAR 大幅降低 token 消耗**：通过选择策略动态切断无效的同伴参考，保留有益的推理交换。例如 GPT-4o-mini 上数学任务平均 token 从 MAD 的 22.2K 降至 11.1K，QA 从 19.5K 降至 8.4K。

3. **规模扩展性好**：随着智能体数量和辩论轮数增加，DEAR 性能持续提升且收敛更快；在高级闭源模型（Claude-4.5-Sonnet、Gemini-3.1-Flash-Lite）上同样表现优异。

4. **Selection RL-Agent 贡献最大**：消融实验表明，选择策略是驱动辩论质量的核心组件；DST 融合优于简单均值池化。

5. **多样性配置与辩论关系调节正交**：DEAR 在 L1~L4 各级多样性配置下均优于 MAD，说明其效果的来源是关系调节而非特定多样性设置。

6. **跨域零样本迁移有效**：RL 智能体学习到的是任务无关的调节策略，跨域迁移仍优于标准 MAD。

## 7. 优点

1. **视角创新**：从个体评估转向群体互动，将"辩论关系"作为核心调节对象，准确抓住了盲从作为群体现象的本质。

2. **任务无关性**：群体证据基于语义相似度而非任务特化特征，天然适用于多种任务和模型，不依赖模型的内部 token 概率（对闭源模型友好）。

3. **不微调 LLM 参数**：仅训练两个轻量 RL 智能体，实用性强。

4. **理论支撑坚实**：采用 HAPPO 保证异构智能体联合策略的单调改进；DST 证据融合为共识/分歧的区分提供了理论基础；主观逻辑为不确定性建模提供了严谨框架。

5. **Token 效率显著**：在提升准确率的同时大幅降低计算开销，兼顾性能与成本。

6. **实验完备**：覆盖多模型、多任务、多规模、多基线，且包含跨域迁移、稀疏拓扑对比和多样性配置分析，论证较为立体。

## 8. 不足与局限

1. **额外训练开销**：虽然推理阶段 token 消耗低，但 RL 智能体的训练仍需数小时 GPU 时间和约 20GB 显存，对资源受限场景存在一定门槛。

2. **跨域迁移存在性能衰减**：Math→QA 迁移（如 TruthfulQA 从域内 83.5% 降至 76.0%）和 QA→Math 迁移均有明显降幅，说明分布偏移会干扰 RL 智能体的决策质量。

3. **两智能体架构的局限**：仅包含"选择"和"行为"两类调节手段，未覆盖更多调控维度（如推理深度、消息内容改写、多轮记忆管理等），可能遗漏更优的调控空间。

4. **数据集与任务的覆盖仍有边界**：主要聚焦数学推理与 QA 选择任务，未覆盖生成式任务（如代码生成、开放规划）和多模态场景；论文虽在附录补充了 IMOAnswerBench、MedXpertQA，但未涉及视觉推理等更复杂的能力域。

5. **依赖预训练编码器**：BGE-M3 编码器的嵌入质量直接影响相似度计算的有效性，对编码器适应性未做消融分析。

6. **两阶段训练目标**：DEAR 仅在 GSM8K 和 ARC-C 两个数据集上训练，跨任务泛化虽被验证，但训练集的覆盖广度有限，最优训练策略（是否需要在更多元的数据上训练）尚未研究。

7. **默认配置较固定**：主实验仅默认 3 个智能体和 3 轮辩论，虽然附录有扩展实验，但更多智能体/更多轮数下的最优超参数配置未做系统讨论。
