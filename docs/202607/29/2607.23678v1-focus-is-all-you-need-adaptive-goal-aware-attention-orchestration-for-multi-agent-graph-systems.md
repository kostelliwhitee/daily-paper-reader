## 摘要
大型语言模型（LLM）使得自主智能体能够进行推理、规划和工具使用。最近的系统越来越多地将这些智能体组织为专门化、互连节点的图。虽然基于图的编排支持灵活的分解和协调，但它带来了一个关键挑战：注意力分配。随着工作流的增长，现有方法通常均匀地执行图组件，将资源浪费在无关或低影响的任务上。我们引入了注意力编排，这是一种将Transformer风格的注意力从令牌表示扩展到工作流级别智能体协调的范式。我们的框架自适应目标感知注意力编排（AGAO）基于用户目标、图依赖关系和计算约束动态估计智能体重要性。AGAO结合了三个组件：（1）目标感知注意力，衡量用户目标与智能体能力之间的语义相关性；（2）拓扑感知注意力，建模智能体图中的结构依赖关系；（3）资源感知注意力，跨异构智能体分配预算和执行优先级。这些机制共同将静态智能体图转变为自适应系统，将计算集中在目标关键推理路径上。跨多种多智能体工作负载的实验表明，与现有基于图的执行策略相比，AGAO提高了任务效率，同时减少了不必要的计算、延迟和令牌消耗。我们的工作将注意力工程确立为可扩展、智能多智能体系统的一个方向。代码：https://github.com/MingzhouFan97/AGAO。

## Abstract
Large language models (LLMs) enable autonomous agents for reasoning, planning, and tool use. Recent systems increasingly organize these agents as graphs of specialized, interconnected nodes. Although graph-based orchestration supports flexible decomposition and coordination, it creates a key challenge: \textbf{attention allocation}. As workflows grow, existing approaches often execute graph components uniformly, wasting resources on irrelevant or low-impact tasks. We introduce \textbf{Attention Orchestration}, a paradigm that extends Transformer-style attention from token representations to workflow-level agent coordination. Our framework, \textbf{Adaptive Goal-aware Attention Orchestration (AGAO)}, dynamically estimates agent importance based on user objectives, graph dependencies, and computational constraints. AGAO combines three components: (1) goal-aware attention, measuring semantic relevance between user goals and agent capabilities; (2) topology-aware attention, modeling structural dependencies in agent graphs; and (3) resource-aware attention, allocating budgets and execution priorities across heterogeneous agents. Together, these mechanisms transform static agent graphs into adaptive systems that focus computation on goal-critical reasoning paths. Experiments across diverse multi-agent workloads show that AGAO improves task effectiveness while reducing unnecessary computation, latency, and token consumption compared with existing graph-based execution strategies. Our work establishes \textbf{Attention Engineering} as a direction for scalable, intelligent multi-agent systems. Code: https://github.com/MingzhouFan97/AGAO.

# 方法论

## 核心思想
- 将智能体图视为动态可选择的计算单元，执行时根据用户目标、图依赖关系和计算约束实时调整每个智能体的“注意力分数”，从而决定哪些智能体被激活、分配多少资源、以及如何排序。
- 注意力分数由三个互补组件融合：目标感知、拓扑感知、资源感知，并通过反馈循环在多个执行步骤中动态更新。

## 关键技术细节
1. **目标感知注意力（Goal-aware Attention）**  
   - 将用户目标编码为查询向量$Q_g$，每个智能体的能力描述、历史统计、当前状态拼接为表示$z_i$，投影为键$K_i$和值$V_i$。  
   - 计算点积注意力：$e_i = Q_g K_i^T / \sqrt{d}$，softmax归一化得到$\alpha_i^{\text{goal}}$，代表语义相关性。

2. **拓扑感知注意力（Topology-aware Attention）**  
   - 提取每个节点的结构特征（依赖距离、前驱/后继影响、中心性等），构造拓扑偏置矩阵$B_G$，加入标准注意力中：$A^{\text{topo}} = \text{softmax}(QK^T/\sqrt{d} + B_G)$。  
   - 计算每个节点的拓扑重要性$\alpha_i^{\text{topo}}$，并与语义注意力加权融合：$\alpha_i^{\text{graph}} = \gamma \alpha_i^{\text{goal}} + (1-\gamma)\alpha_i^{\text{topo}}$。

3. **资源感知注意力（Resource-aware Attention）**  
   - 基于融合后的注意力分数$\alpha_i^*$，转化为三类执行控制：  
     - 模型路由：分配到强/中/弱三种推理模型（依据阈值$\tau_h, \tau_l$）。  
     - 令牌预算分配：$T_i = T_{\text{total}} \cdot \exp(\alpha_i^*) / \sum_j \exp(\alpha_j^*)$。  
     - 执行优先级：$P_i = \alpha_i^* \cdot w_i$（$w_i$为执行紧迫度）。  
   - 优化目标：在预算约束下最大化总效用$\sum \alpha_i^* U_i(r_i)$。

4. **自适应图路由（Adaptive Graph Routing）**  
   - 每步执行后，根据中间观测结果（输出、状态、反馈）更新注意力：$\alpha^{t+1} = \lambda_1 \alpha_{\text{goal}}^t + \lambda_2 \alpha_{\text{topo}}^t + \lambda_3 \alpha_{\text{feedback}}^t$。  
   - 根据更新后的分数决定每个节点：执行、挂起或剪枝（通过阈值$\tau_e, \tau_s$控制）。

## 算法流程（文字说明）
1. 初始化执行状态和注意力分布，编码用户目标。  
2. 循环（直到任务完成）：  
   - 计算目标感知注意力 → 拓扑感知注意力 → 融合为当前注意力分布。  
   - 资源分配器根据注意力分数和总预算分配各智能体资源。  
   - 选择注意力分数高于执行阈值的智能体，按其分配的资源执行。  
   - 观察执行反馈，更新注意力状态和图状态。  
3. 聚合所有执行步骤的输出，返回最终响应。

# 实验设计

- **数据集/场景**：两套共16个任务：  
  - **MBPP编程任务**（8个）：Python编程题，评估pass@1。  
  - **HotpotQA多跳问答任务**（8个）：评估token级F1。  
- **基准系统与图结构**：每个任务使用手工指定的9节点图：编程图包含规格分析、实现、测试、调试、审查、终稿等角色；问答图包含分解、检索、证据选择、推理、验证、终稿等角色。任务清单、图模板、提示、工具、重试行为及每次运行预算固定。  
- **对比方法**（5种策略）：
  - **Random**：依赖有效、固定种子的随机路由器，最多选择两个就绪节点。  
  - **Static**：按固定图顺序执行所有依赖有效的节点。  
  - **Semantic**：根据任务提示与节点能力描述的词法重叠选择最多两个就绪节点。  
  - **MoE-style**：使用固定词法相关性与拓扑分数混合（无反馈/自适应资源路由）选择最多两个就绪节点。  
  - **AGAO**：结合词法目标相关性、拓扑分数和基于规则的反馈；可跳过低分节点，并将选定节点路由到低/中/高容量模型层。  
- **评估指标**：任务质量（pass@1或F1）、活跃节点数、累计智能体时间、输入/输出token数。

# 主要结论与发现

1. **AGAO在MBPP上表现最佳**：pass@1达到0.875（7/8任务解决），超越MoE-style（0.75）、Static（0.625）、Random和Semantic（0.5）。  
2. **AGAO在HotpotQA上F1为0.340**，低于MoE-style（0.417），但高于其他基线；作者指出AGAO效果因工作负载而异。  
3. **AGAO大幅降低计算开销**：相比Static，活跃节点减少27.8% (MBPP) 和19.4% (HotpotQA)；累计智能体时间减少56.0% 和50.3%。  
4. **资源消耗分析**：AGAO使用了更多输入token（因路由和上下文构建），但输出token显著减少。由于输出token成本通常是输入token的6倍，AGAO在经济上更高效。  
5. **消融实验**：完整AGAO在两个套件上提供了最稳定的质量和效率平衡；去除任何单一组件都会在某个指标上造成明显下降或引入权衡。
