## 摘要
我们研究了一个去中心化的强化学习问题，涉及多个智能体，它们与同一个马尔可夫决策过程（MDP）进行交互。智能体可以在网络上交换信息，共同学习最优状态-动作价值函数。针对这一设定，我们提出了一种新颖的基于epoch的分布式Q学习算法，称为VRDQ，其中在每个epoch内，智能体局部估计贝尔曼最优性算子，并通过基于共识的协议扩散信息。对于静态和时变网络，我们为VRDQ建立了高概率的有限时间收敛速率，这些速率因协作而具有线性加速。关键的是，我们证明样本复杂度上的这种加速仅需要~O(1)的通信，显著优于先前工作中的通信成本。

## Abstract
We investigate a decentralized reinforcement learning problem involving multiple agents that interact with the same Markov Decision Process (MDP). The agents can exchange information over a network to collectively learn the optimal state-action value function. For this setting, we introduce a novel epoch-based distributed $Q$-learning algorithm called VRDQ, where within each epoch, agents locally estimate the Bellman optimality operator and diffuse information using a consensus-based protocol. For both static and time-varying networks, we establish high-probability finite-time convergence rates for VRDQ that enjoy linear speedups from collaboration. Crucially, we prove that such speedups in sample-complexity require only $\tilde{O}(1)$ communication, substantially improving upon the communication costs in prior work.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **方差缩减**：智能体不每步更新Q表，而是将样本分成若干**epoch**，在每epoch内局部估计贝尔曼最优性算子（利用多步样本来估计转移概率，而非单步采样），得到低方差的算子估计。
- **扩散与解耦**：每epoch内，智能体并行进行两阶段：
    - 局部算子估计（贯穿整个epoch）；
    - 在前L步进行基于共识的平均扩散（传播上一epoch的更新方向）。
- 仅在每epoch结束时更新一次Q表，从而大幅减少通信次数。

### 关键技术细节
- **局部算子估计**（公式7）：每个智能体 i 在 epoch k 内收集 H 个独立样本，估计转移核 $\hat{P}_{i,k}$，构造经验贝尔曼算子：
  $$\hat{T}_{i,k} f(s,a) = R(s,a) + \gamma \sum_{s'} \hat{P}_{i,k}(s'|s,a) \max_{a'} f(s',a')$$
- **扩散**（公式8）：初始方向 $d^{(0)}_{i,k} = \hat{T}_{i,k-1} Q_{i,k}$，然后执行 L 轮加权平均：
  $$d^{(\ell+1)}_{i,k} = \sum_{j \in N_i} (W)_{ij} d^{(\ell)}_{j,k}$$
  得到最终扩散值 $d^{(L)}_{i,k}$。
- **Q表更新**（公式11）：$Q_{i,k+1} = (1-\alpha) Q_{i,k} + \alpha d^{(L)}_{i,k}$。
- **参数选择**（公式13）：$\alpha = \frac{\log(NT)}{(1-\gamma)K}$，$K = \lceil c_1 \log(NT)/(1-\gamma) \rceil$，$L = \lceil \log(c_2 N^{3/2} \sqrt{T} \sqrt{1-\gamma}) / \log(1/\rho) \rceil$。其结果使得通信次数 $KL = O(\log^2(NT))$。
