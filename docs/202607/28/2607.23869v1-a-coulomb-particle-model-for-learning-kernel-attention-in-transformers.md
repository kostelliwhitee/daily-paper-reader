## 摘要
随机特征为核机器提供了可扩展的近似，但其性能在很大程度上取决于特征分布的选择。我们提出了一种基于粒子的方法，通过优化核-目标对齐，并利用Riesz/库仑排斥势对粒子进行正则化，来学习该分布。得到的哈密顿量产生了多样化的、任务自适应的随机特征，并通过McKean-Vlasov方程允许平均场描述。我们将该方法实例化到线性化Transformer注意力中，在第一对齐阶段学习正随机特征映射，然后冻结核，并使用交叉熵训练剩余网络参数。在合成分类和句子级基准上的实验表明，学习到的核化注意力可以在保持线性注意力推理复杂度的同时，提高多种特征映射的准确性、校准性和鲁棒性。

## Abstract
Randomized features provide a scalable approximation to kernel machines, but their performance depends strongly on the choice of feature distribution. We propose a particle-based method that learns this distribution by optimizing kernel-target alignment while regularizing particles with a Riesz/Coulomb repulsive potential. The resulting Hamiltonian yields diverse, task-adaptive random features and admits a mean-field description through a McKean--Vlasov equation. We instantiate the method in linearized Transformer attention by learning positive random-feature maps in a first alignment phase, then freezing the kernel and training the remaining network parameters with cross-entropy. Experiments on synthetic classification and sentence-level benchmarks show that learned kernelized attention can improve accuracy, calibration, and robustness for several feature maps while preserving linear-attention inference complexity.

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 将随机特征参数视为“粒子”，在相空间中进行演化。借助粒子哈密顿量（Hamiltonian）同时优化两个目标：
  1. **吸引项**：通过核-目标对齐，奖励那些使核矩阵与标签对齐的粒子；
  2. **排斥项**：通过Riesz/Coulomb势（如$\|\omega\|^{-s}$或$-\log\|\omega\|$）惩罚粒子间的接近，促进多样性，防止坍缩（collapse）。

### 关键技术细节
- **哈密顿量**（有限粒子形式）：
  \[
  H_N(\Omega_N) = -\frac{1}{n(n-1)}\sum_{i\neq j}y_i y_j \frac{1}{N}\sum_{k=1}^N \phi_{\omega_k}(x_i)\phi_{\omega_k}(x_j) + \lambda W_{N,s}(\Omega_N)
  \]
  其中第一项为对齐损失（期望最大化），第二项为Riesz/Coulomb排斥互作用。
- **连续平均场极限**：当粒子数 $N\to\infty$、步长 $\eta_N\to0$ 时，系统收敛到McKean–Vlasov方程描述的密度演化：
  \[
  \partial_t\rho_t = \nabla\cdot(\rho_t\nabla U_t) + \beta^{-1}\Delta\rho_t
  \]
  其中 $U_t = V_D + \lambda g_s * \rho_t$，$V_D$ 是数据诱导势。这对应Wasserstein梯度流，自由能 $F_\beta(\rho)=E_s(\rho)+\beta^{-1}\text{Ent}(\rho|\ell)$ 单调递减。
- **大偏差原理**：学习到的经验核 $K_{\mu^N}$ 以指数速度收敛到任务自适应变分核 $K_{\mu^\star_s}$。
- **算法流程**（两阶段）：
  - **Phase A（对齐阶段）**：仅优化特征粒子 $\Omega_N$，使用投影Langevin动力学（Algorithm 1）：
    \[
    \omega_k^{m+1} = P_\Omega\left(\omega_k^m - \eta N\nabla_{\omega_k} H_N(\Omega_N^m) + \sqrt{2\eta/\beta}\,\xi_k^m\right)
    \]
    通过核-目标对齐损失（公式C.4/C.5）和Riesz斥力，学习任务自适应特征分布。
  - **Phase B（冻结交叉熵训练）**：固定已学习的 $\Omega_N$，使用标准交叉熵训练其余Transformer参数（如FFN、分类头）。

- **在注意力中的应用**：将标准softmax注意力替换为**正随机特征核注意力**（linearized attention）：
  \[
  \hat{a}_i(X) = \frac{\phi_{\Omega_N}(q_i)^\top\left(\sum_j\phi_{\Omega_N}(k_j)v_j^\top\right)}{\phi_{\Omega_N}(q_i)^\top\left(\sum_j\phi_{\Omega_N}(k_j)\right)}
  \]
  通过使用不同的正特征映射（favor、ELU+1、softplus、sigmoid²、cos²、PORF-softplus等）实例化。

## 6. 主要结论与发现
1. **粒子优化提升性能**：在合成分类中，优化后的粒子（Langevin方法）相比于固定RFF或重要性采样基线，在准确率和F1上均有显著提升，尤其在中高噪声区域。
2. **稀疏特征预算下更有效**：在64特征/头时，优化粒子保持约90%的256特征性能，而固定RFF退化更严重。
3. **NLP任务上的表现**：
   - SST-2上，Kernel-porf-softplus获得最高准确率（0.8188）和MCC（0.6376）；Kernel-favor获得最低ECE（0.3086）；Kernel-cos2获得最低Brier（0.1366）；部分Kernel改进了LogLoss和Brier。

   - Rotten Tomatoes上，Kernel-softmaxfeat同样获得最佳Acc（0.7167）、MCC、LogLoss、Brier。
4. **对特征映射敏感**：并非所有Kernel变体都一致优于Vanilla；例如Kernel-softplus在SST-2上Brier和ECE反而变差。
5. **推理复杂度不变**：学习过程增加训练时间（约2倍），但推理时仍为线性复杂度（O(ℓM)）。
